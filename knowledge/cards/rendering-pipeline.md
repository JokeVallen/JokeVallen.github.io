## 定义

渲染管线是 GPU 把三维场景数据转换成屏幕像素的处理流程，现代管线通常分为应用阶段、几何阶段、光栅化阶段和逐片元阶段。

## 主要阶段

| 阶段 | 主要工作 |
|---|---|
| 应用阶段 | CPU 准备网格、材质、相机和绘制调用 |
| 几何阶段 | 顶点变换、裁剪、投影、屏幕映射 |
| 光栅化阶段 | 把三角形转换为片元并计算覆盖 |
| 片元阶段 | 逐片元着色、纹理采样、光照计算 |
| 输出合并 | 深度/模板测试、混合、写入帧缓冲 |

## 数据流

顶点数据从 CPU 提交到 GPU，经过顶点着色器处理，再被组装成图元，随后光栅化为片元。片元着色器输出颜色，最后经过输出合并写入渲染目标。

## 常见坑

- CPU 提交过多 Draw Call 会造成应用阶段瓶颈。
- 片元着色器过于复杂会造成 GPU 像素吞吐瓶颈。
- 管线中的坐标空间变换错误会导致模型不可见或翻转。

- 管线阶段可能因图形 API 和硬件而合并或流水化。

> 记忆：**应用准备，几何变换，光栅成片元，片元着色，输出合并。**
