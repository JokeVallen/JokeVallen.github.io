## 定义

C# 内置基元类型的大小由 CTS 和运行时决定，常用类型在 32 位和 64 位平台上大小基本固定，但 `IntPtr` 和引用大小会随平台变化。

## 常见类型大小

| 类型 | 字节数 | 说明 |
|---|---|---|
| `bool` | 1 | 逻辑值 |
| `byte` / `sbyte` | 1 | 无符号 / 有符号 |
| `short` / `ushort` | 2 | 16 位整数 |
| `int` / `uint` | 4 | 32 位整数 |
| `long` / `ulong` | 8 | 64 位整数 |
| `float` | 4 | 单精度浮点 |
| `double` | 8 | 双精度浮点 |
| `decimal` | 16 | 高精度十进制 |
| `char` | 2 | UTF-16 代码单元 |
| `IntPtr` | 4 或 8 | 取决于平台 |

## 常见坑

- 对象实例还有对象头、方法表指针和对齐开销，不等于字段大小之和。
- `bool` 在数组中可能按 1 字节存储，但内存布局不保证。
- 序列化和网络协议应使用明确宽度的类型，不要依赖平台默认布局。

## 补充要点

- `nint` 和 `nuint` 是平台相关整数，大小随进程位数变化。
- 结构体默认布局可能包含对齐填充，字段顺序会影响力大小。
- 使用 `Marshal.SizeOf` 可获取非托管布局大小。

> 记忆：**整数按 1、2、4、8 递增；decimal 16，char 2，指针看平台。**
