## 定义

双向链表的每个节点同时保存前驱和后继指针，可以双向遍历，也能在已知节点位置时以 O(1) 时间插入或删除。

## 节点结构

```csharp
public class Node<T>
{
    public T Value;
    public Node<T> Prev;
    public Node<T> Next;
}
```

## 复杂度

| 操作 | 复杂度 | 说明 |
|---|---|---|
| 头部插入 | O(1) | 修改 head 和旧头节点 |
| 尾部插入 | O(1) | 维护 tail 指针时 |
| 已知节点删除 | O(1) | 通过 prev/next 直接摘除 |
| 按值查找 | O(n) | 需要从头或尾遍历 |
| 顺序遍历 | O(n) | 支持正向和反向 |

## 常见坑

- 删除节点时先保存前后指针，再断开当前节点，避免断链。
- 头节点和尾节点的 `prev`/`next` 要单独处理或使用哨兵节点。
- 双向链表每个节点多存一个指针，内存开销高于单向链表。

## 补充要点

- 哨兵节点可以统一处理头尾插入删除，减少边界分支。
- 双向链表适合实现 LRU 缓存，配合哈希表可做到 O(1) 访问和淘汰。
- 与数组相比，链表不要求连续内存，但缓存局部性较差。

> 记忆：**prev 加 next，双向可走；已知节点删插 O(1)，查找仍 O(n)。**
