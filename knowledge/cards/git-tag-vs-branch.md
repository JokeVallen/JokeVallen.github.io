## 结论

分支会随新提交不断移动，标签永远固定在打标签时的那次提交上。

## 对比

| 维度 | 分支 | 标签 |
|---|---|---|
| 是否移动 | 会移动 | 不移动 |
| 指向 | 最新提交 | 指定提交 |
| 用途 | 持续开发 | 标记版本 |
| 示例 | `main`、`dev` | `v1.0`、`stable` |

## 类比

- 分支像火车轨道，火车头不断向前。
- 标签像站牌，火车开走后站牌仍在原地。

## 使用场景

- 每次发布稳定版本时打标签：`v1.0`、`v1.1`。
- 日常开发提交继续放在分支上。
- 回退时可以直接使用标签名，不必记提交 ID。

## 常用命令

```bash
git branch
git tag
git tag -a v1.0 -m "稳定版本"
git reset --mixed v1.0
```

> 记忆：分支会跑，标签钉死；开发用分支，存档用标签。
