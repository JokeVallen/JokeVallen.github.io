## 定义

稳定选择排序仍每轮选最小值，但不用交换，而是把最小值取出，将中间元素整体右移，再把最小值放到空位。

## 核心步骤

1. 在未排序区找到最小元素下标 `minIndex`。
2. 保存 `min = nums[minIndex]`。
3. 把 `[i, minIndex - 1]` 的元素整体右移一位。
4. 把 `min` 写入 `nums[i]`。

## 复杂度与稳定性

| 指标 | 结果 |
|---|---|
| 比较次数 | O(n²) |
| 移动次数 | O(n²) |
| 空间 | O(1) |
| 稳定性 | 稳定 |

## 代码示例

```csharp
var min = nums[minIndex];
for (int j = minIndex; j > i; j--)
    nums[j] = nums[j - 1];
nums[i] = min;
```

## 常见坑

- 移位法用更多移动换取稳定性，元素移动次数可能明显高于交换法。
- 必须从后向前搬移，否则会覆盖尚未处理的数据。
- 只比较 `<`，遇到相等元素不更新 `minIndex`，相等元素的相对顺序得以保留。

## 适用场景

- 需要稳定排序但数据量不大的场合。
- 交换元素代价高、移动元素代价可接受。
- 教学时用来对比“交换法”和“移位法”的差异。

> 记忆：**选最小，不交换；中间整体右移，最小值补空位。**
