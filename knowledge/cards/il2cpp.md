## 定义

IL2CPP 是 Unity 的脚本后端。它把 C# 编译出的 IL 转换为 C++ 代码，再交由平台原生编译器生成机器码，实现提前编译。

## 处理流程

1. Roslyn 把 C# 编译为 IL 程序集。
2. IL2CPP 把 IL 转换为 C++。
3. 平台 C++ 编译器把 C++ 编译为原生二进制。
4. 运行时通过 IL2CPP 虚拟机提供 GC、反射等支持。

## 特点

| 维度 | 说明 |
|---|---|
| 编译时机 | AOT，构建期生成原生代码 |
| 性能 | 通常优于 Mono JIT，启动更稳定 |
| 平台支持 | iOS 等禁止 JIT 的平台必需 |
| 包体 | 通常更大，构建时间更长 |
| 泛型与反射 | 部分动态代码需要额外保留或 AOT 处理 |

## 常见坑

- 动态生成代码、反射调用和泛型实例可能因裁剪或 AOT 限制失败。
- 构建时间明显长于 Mono，迭代时可用 Mono 开发。
- 需要关注 `link.xml` 和代码裁剪配置。

## 补充要点

- 构建时会生成 C++ 中间代码，并针对每个目标平台分别编译。
- 代码裁剪会移除未引用的类型和成员，反射使用的类型需要保留。
- IL2CPP 通常有更稳定的运行性能和更低的内存碎片风险，但包体更大。

> 记忆：**IL 转 C++，再编原生码；AOT 提前编译，iOS 必备。**
