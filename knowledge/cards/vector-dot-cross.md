## 点乘 Dot（结果：标量）

```
a · b = ax*bx + ay*by + az*bz = |a||b|cosθ
```

衡量两个向量的**同向程度**：

| 结果 | 含义 |
|---|---|
| > 0 | 夹角 < 90°，大致同向 |
| = 0 | 垂直 |
| < 0 | 夹角 > 90°，大致反向 |

**用途**：前后判断、求夹角、光照漫反射 `N·L`。

**坑**：`Vector3.Dot` 不能求距离，求距离用 `Vector3.Distance`。

## 叉乘 Cross（结果：Vector3）

```
a × b = (ay*bz - az*by,
         az*bx - ax*bz,
         ax*by - ay*bx)
```

- 结果**同时垂直于 a 和 b**
- 模长 `|a||b|sinθ` = 平行四边形面积
- 方向遵循**左手定则**（Unity 左手坐标系）

**用途**：求法线、判断左右、求面积、判断顺逆时针。

`Vector3.Cross(forward, dir).y > 0` → 目标在右侧。

## 对比

| 维度 | 点乘 | 叉乘 |
|---|---|---|
| 结果 | 标量 | 向量 |
| 核心 | `|a||b|cosθ` | `|a||b|sinθ` |
| 用途 | 夹角、前后 | 垂直、面积 |
| 为 0 时 | 垂直 | 平行 |

> 口诀：**点乘管夹角，叉乘管垂直；点乘得数，叉乘得向量。**
