## 定义

托管资源是由 .NET 运行时分配在托管堆上的对象，例如普通 class 实例、数组、字符串和委托，由垃圾回收器自动回收。

## 特点

- 对象引用不再可达后，GC 会在某个时间点回收。
- 分配通常很快，回收可能造成短暂停顿。
- 大对象会进入大对象堆，回收成本更高。
- 开发者不需要手动 `delete`，但要避免不必要的分配。

## 代码示例

```csharp
var list = new List<int>();
list.Add(1);
```

`list` 指向的对象由 GC 管理，离开作用域后只需等待回收。

## 常见坑

- 托管资源不等于“没有资源问题”，事件订阅、静态引用仍会造成对象无法回收。
- 频繁创建临时对象会增加 GC 压力，热路径应复用对象。
- `GC.Collect()` 通常不应手动调用，会破坏 GC 的分代假设。

> 记忆：**托管资源归 GC，自动回收；少分配、断引用才是优化关键。**
