## 定义

光栅操作是片元写入帧缓冲前执行的一组逐像素操作，包括深度测试、模板测试、Alpha 测试、混合和颜色掩码。

## 常见操作

| 操作 | 作用 |
|---|---|
| 深度测试 | 根据深度决定是否保留片元 |
| 模板测试 | 用模板缓冲控制片元区域 |
| Alpha 测试 | 根据透明度丢弃片元 |
| 混合 | 把源颜色与目标颜色按公式混合 |
| 颜色掩码 | 控制写入哪些颜色通道 |

## 混合公式

常见 Alpha 混合为：

```text
结果 = 源颜色 * 源系数 + 目标颜色 * 目标系数
```

例如：

```text
srcAlpha, oneMinusSrcAlpha
```

## 常见坑

- 透明物体需要正确排序，混合结果依赖渲染顺序。
- 深度测试与深度写入要匹配透明/不透明需求。
- 大量半透明叠加会造成严重过度绘制。

## 补充要点

- 混合系数由源和目标颜色分量决定，常见如 SrcAlpha 与 OneMinusSrcAlpha。
- 深度写入通常在透明物体上关闭，避免遮挡后方透明物体。
- 模板缓冲可用于描边、遮罩和传送门等效果。

> 记忆：**片元进帧缓冲前，先测深度模板，再混合写入。**
