## 定义

`static` 表示成员属于类型本身，而不是某个实例。静态成员在类型加载后共享一份，可通过类名直接访问。

## 常见用法

| 用法 | 说明 |
|---|---|
| 静态字段 | 所有实例共享 |
| 静态方法 | 不依赖实例状态 |
| 静态类 | 不能被实例化，只能包含静态成员 |
| 静态构造函数 | 类型首次使用前执行一次 |

## 代码示例

```csharp
public class Counter
{
    public static int Total;
    public static void Add() => Total++;
}
```

## 常见坑

- 静态字段会长期持有引用，容易造成内存泄漏或全局状态。
- 静态方法不能直接访问实例成员。
- 静态成员在多线程环境下需要额外的同步措施。

## 补充要点

- 静态类不能包含实例成员，常用于工具类和扩展方法容器。
- 常量和静态只读字段都是类型级成员，但初始化时机不同。
- 泛型类的静态字段会按每个封闭类型分别初始化。

> 记忆：**static 属于类型不属于实例，共享一份，全局可见。**
