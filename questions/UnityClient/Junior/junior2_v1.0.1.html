一、客观题

C# 基础

1. 关于值类型与引用类型的赋值语义，正确的是？
A. 值类型赋值复制引用，引用类型赋值复制值　B. 值类型赋值复制值，引用类型赋值复制引用　C. 两者赋值都复制引用　D. 两者赋值都复制值

  • 正确答案：B
  • 解析：值类型赋值复制值；引用类型赋值复制引用，两个变量指向同一对象。

2. 关于 params 关键字，正确的是？
A. 只能用于引用类型参数　B. 调用时必须显式传入参数数组　C. 用于可变参数，调用时可直接传入离散元素，编译器自动打包为数组　D. 一个方法可以定义多个 params 参数

  • 正确答案：C
  • 解析：params 用于可变参数，调用时可直接传离散元素，编译器自动打包为数组；只能有一个且放最后。

3. 关于可选参数与命名参数，正确的是？
A. 可选参数必须放在参数列表最前面　B. 可选参数必须位于必选参数之后　C. 命名参数不能打乱实参顺序　D. 命名参数不能跳过可选参数

  • 正确答案：B
  • 解析：可选参数必须位于必选参数之后；命名参数可打乱实参顺序，也可与位置参数混用。

4. 关于方法重载与重写，正确的是？
A. 重载发生在父子类之间　B. 重写是子类用 override 改写父类虚方法　C. 重写发生在同一个类中　D. 重载要求方法签名一致

  • 正确答案：B
  • 解析：重载在同一类中方法名相同、参数列表不同；重写是子类用 override 改写父类虚方法。

5. 关于空合并 ?? 与空条件 ?.，正确的是？
A. a ?? b 在 a 不为 null 时返回 b　B. a ?? b 在 a 为 null 时返回 b　C. a?.b 在 a 为 null 时抛异常　D. 两者都不能用于值类型

  • 正确答案：B
  • 解析：a ?? b 在 a 为 null 时返回 b；a?.b 在 a 为 null 时返回 null 不抛异常。

6. 关于索引器，正确的是？
A. 索引器就是数组字段　B. 索引参数类型只能是 int　C. 索引参数类型可不固定　D. 一个类只能有一个索引器

  • 正确答案：C
  • 解析：索引器用 this[…] 定义，索引参数类型不限（如 string、enum），且可重载。

7. 关于元组与解构，正确的是？
A. 元组只能包含两个元素　B. ValueTuple 是引用类型　C. (int x, int y) = (1, 2) 是解构赋值　D. 元组不能作为方法返回值

  • 正确答案：C
  • 解析：元组用 ValueTuple 表示（值类型），可含多个元素；解构可把元组拆分到变量。

8. 关于静态类与分部类，正确的是？
A. 分部类用 partial 拆分到多个文件　B. 静态类可以被实例化　C. 分部类必须同名同文件　D. 静态类不能有静态构造函数

  • 正确答案：A
  • 解析：分部类用 partial 拆分到多个文件，编译时合并；静态类只能含静态成员、不能被继承。

9. 关于 Array 与 List<T>，正确的是？
A. List<T> 可动态扩容　B. List<T> 的长度不能超过容量　C. Array 可动态扩容　D. List<T> 不能像 Array 一样通过索引访问

  • 正确答案：A
  • 解析：Array 长度固定；List<T> 内部数组可动态扩容，超过容量时扩容并复制。

10. 关于 C# 扩展方法，正确的是？
A. 可以重写被扩展类型的现有方法　B. 只能定义在实例类中　C. 可以访问被扩展类型的私有成员　D. 定义在静态类中的静态方法

  • 正确答案：D
  • 解析：扩展方法定义在静态类中、第一个参数前加 this，编译为静态方法调用，不能重写现有方法。

11. 关于静态构造函数，正确的是？
A. 每次 new 都会调用一次　B. 可以通过代码显式调用　C. 可以带修饰符和参数　D. 在类型第一次被使用前由 CLR 自动调用一次

  • 正确答案：D
  • 解析：静态构造函数在类型第一次被使用前由 CLR 调用一次，无访问修饰符、无参数，不能显式调用。

12. 关于 IComparable 与 IComparer，正确的是？
A. IComparable 是外部比较器　B. IComparer 返回值类型是 bool　C. IComparable 由元素自身实现　D. IComparer 由元素自身实现

  • 正确答案：C
  • 解析：IComparable 由元素自身实现 CompareTo；IComparer 是外部比较器，传入 Sort 使用。

13. 关于 C# 的 Task 与 Thread，正确的是？
A. Task 通常基于线程池调度　B. Task 是 Thread 的上层封装　C. Thread 是 Task 的上层封装　D. Task 同步执行，Thread 才能异步

  • 正确答案：A
  • 解析：Task 是更高级的异步抽象，通常基于线程池调度；Thread 是更底层的线程。

14. 关于构造函数执行顺序，正确的是？
A. 派生类构造函数先于基类执行　B. 派生类只能执行基类的无参构造函数　C. 基类构造函数先于派生类构造函数执行　D. 基类构造函数是否执行由派生类决定

  • 正确答案：C
  • 解析：基类构造函数先于派生类构造函数执行；有 base() 调用时先执行基类构造。

15. 关于运算符重载，正确的是？
A. 可以重载 = 赋值运算符　B. 可以重载 && 和 ||　C. 可重载 +、-、==　D. 只能重载算术运算符

  • 正确答案：C
  • 解析：运算符重载用 operator 定义静态方法，可重载 +、-、== 等；可重载的运算符有明确规定。

16. 关于 var 与 dynamic，正确的是？
A. var 编译时推导类型　B. var 是运行时类型但不跳过编译检查　C. dynamic 是编译时类型　D. var 是运行时类型且跳过编译检查

  • 正确答案：A
  • 解析：var 编译时推导类型；dynamic 运行时解析、跳过编译期类型检查。

17. 关于模式匹配，正确的是？
A. 模式匹配只能用于 switch　B. obj is int i 会在运行时判断类型　C. is 只能判断是否为 null　D. obj is int i 会在编译时进行类型判断

  • 正确答案：B
  • 解析：obj is int i 在运行时判断类型，是则赋值给 i；可用于 if/switch 模式匹配。

18. 在 C# 中，使用 foreach 遍历集合的过程中修改该集合，通常会？
A. 正常遍历，不受影响　B. 抛出 InvalidOperationException　C. 编译期报错　D. 陷入死循环

  • 正确答案：B
  • 解析：foreach 遍历时修改集合会抛 InvalidOperationException（集合版本号变化）。

19. 关于 C# 的 nameof 运算符，正确的是？
A. 底层利用反射获取　B. 编译期确定　C. 运行时确定　D. 每次获取都会返回新的字符串对象

  • 正确答案：B
  • 解析：nameof 由编译器在编译期替换为成员名字符串，不依赖反射、无运行时开销。

20. 关于特性 Attribute，正确的是？
A. 程序集加载时创建实例　B. 参数可以是变量　C. 运行时写入元数据　D. 运行时可通过反射读取

  • 正确答案：D
  • 解析：特性用于附加元数据，运行时通过反射读取；参数必须是编译期常量。

21. 关于 List<T> 的 Capacity 与 Count，正确的是？
A. Capacity 是内部数组容量　B. Capacity 是实际元素个数　C. Count 是内部数组容量　D. Capacity 在实例化后无法修改

  • 正确答案：A
  • 解析：List<T> 的 Capacity 是内部数组容量，Count` 是实际元素个数；Capacity 可手动设置或自动扩容。

22. 关于枚举 Flags 与位运算，正确的是？
A. [Flags] 枚举可用位运算组合多个枚举值　B. 不能用于 short 类型枚举　C. 起始枚举必须从 0 开始　D. 支持像普通枚举一样自动赋值 1,2,3…

  • 正确答案：A
  • 解析：[Flags] 枚举用位运算组合多个值；成员通常赋 2 的幂（1,2,4…）。

23. 关于 checked 与 unchecked，正确的是？
A. checked 开启整型溢出检查并抛出 ArgumentOutOfRangeException　B. 默认始终开启溢出检查　C. unchecked 关闭溢出检查　D. 只影响浮点数

  • 正确答案：C
  • 解析：unchecked 关闭整型溢出检查（默认），checked 开启并抛 OverflowException。

24. 关于多维数组与交错数组，正确的是？
A. int[,] 是交错数组　B. int[][] 是交错数组　C. int[][] 是多维数组　D. 两者是相同语义的不同表示方式

  • 正确答案：B
  • 解析：int[][] 是交错数组（数组的数组，各行可不同长度）；int[,] 是矩形多维数组。

25. 关于 Dictionary<TKey,TValue> 的 TryGetValue，正确的是？
A. 查找成功返回 true 并通过 out 类型参数接收输出值　B. 查找成功返回 true 并通过 ref 类型参数接收输出值　C. 查找失败会抛异常　D. 查找成功则返回结果值，否则返回默认值

  • 正确答案：A
  • 解析：TryGetValue 查找成功返回 true 并通过 out 输出值，避免两次查找（先 ContainsKey 再取）。

Unity 引擎基础

26. 关于 PlayerPrefs，正确的是？
A. 支持存储大量结构化数据　B. 以键值对形式保存少量简单数据　C. 不支持跨平台　D. 用于临时存储，不支持持久化

  • 正确答案：B
  • 解析：PlayerPrefs 以键值对保存少量 int/float/string，跨平台持久化；不适合大量数据。

27. 关于 DontDestroyOnLoad，正确的是？
A. 让对象在当前场景无法被销毁　B. 切换场景时被标记对象依旧会被销毁　C. 显式阻止对象被 GC 回收　D. 切换场景时被标记对象不被销毁

  • 正确答案：D
  • 解析：DontDestroyOnLoad 使对象在切换场景时不被销毁，常用于管理器/音频等常驻对象。

28. 按应用暂停/退出时调用的回调正确的是？
A. OnApplicationPause / OnApplicationQuit　B. OnApplicationQuit / OnApplicationPause　C. OnPause / OnQuit　D. OnQuit / OnPause

  • 正确答案：A
  • 解析：OnApplicationPause/OnApplicationQuit 是应用暂停/退出时调用的回调；注意调用时机与顺序。

29. 关于相机正交与透视投影，正确的是？
A. 正交相机有近大远小效果　B. 透视相机有近大远小效果　C. 透视相机视野中的物体大小不随距离变化　D. 两者渲染结果相同，只是拍摄方式不同

  • 正确答案：B
  • 解析：透视相机有近大远小；正交相机物体大小不随距离变化，常用于 2D/UI。

30. 关于 Collider，正确的是？
A. BoxCollider 是 Unity 内置碰撞器组件　B. TriangleCollider 是 Unity 内置碰撞器组件　C. 没有 Rigidbody 时，Collider 之间也会发生物理碰撞　D. MeshCollider 只能用于 3D

  • 正确答案：A
  • 解析：BoxCollider 是内置碰撞器；没有 Rigidbody 时 Collider 之间不发生物理碰撞（触发器除外）。

31. 关于 OnDestroy 与 OnDisable，正确的是？
A. OnDestroy 在从未激活的对象被销毁时依旧会调用　B. OnDisable 只在游戏退出时调用　C. OnDisable 在对象禁用或销毁时会调用　D. OnDestroy 在对象禁用时调用

  • 正确答案：C
  • 解析：OnDisable 在对象禁用或销毁时调用；OnDestroy 在对象销毁时调用（激活过的对象）。

32. 关于 InvokeRepeating，正确的是？
A. 可以设置调用的时间间隔　B. 不支持延迟调用　C. 无法被取消　D. 可以传入多个参数

  • 正确答案：A
  • 解析：InvokeRepeating 可按延迟与间隔重复调用方法；可用 CancelInvoke 取消。

33. 关于 localPosition 与 position，正确的是？
A. localPosition 是自身相对父对象坐标系的坐标　B. position 是自身相对父对象坐标系的坐标　C. localPosition 与 position 等价　D. localPosition 是自身相对世界坐标系的坐标

  • 正确答案：A
  • 解析：localPosition 是相对父物体坐标系的坐标；position 是世界坐标。

34. 关于 GetAxis 与 GetAxisRaw，正确的是？
A. 两者完全相同　B. GetAxisRaw 带平滑　C. GetAxisRaw 直接返回 -1/0/1 无平滑　D. GetAxis 直接返回 -1/0/1 无平滑

  • 正确答案：C
  • 解析：GetAxis 带平滑过渡；GetAxisRaw 直接返回 -1/0/1，无平滑，适合精确输入。

35. 关于 Application.targetFrameRate，正确的是？
A. 用于设置分辨率　B. 用于设置目标帧率　C. 用于设置屏幕刷新率　D. 用于设置每帧占据的时间

  • 正确答案：B
  • 解析：Application.targetFrameRate 设置目标帧率（配合 vSync 使用）。

36. 关于 Animator 参数，正确的是？
A. 参数无法在运行时通过代码创建　B. Trigger 参数消耗后需要手动重置　C. 参数只能通过代码进行设置　D. 支持 Float、Int、Bool、Trigger 四种类型

  • 正确答案：D
  • 解析：Animator 参数支持 Float/Int/Bool/Trigger 四种类型；Trigger 使用后自动重置。

37. 关于 AudioSource，正确的是？
A. AudioListener 用于播放音频　B. AudioSource 用于监听音频播放　C. AudioClip 是一个音频播放组件　D. AudioSource 用于播放音频

  • 正确答案：D
  • 解析：AudioSource 用于播放音频，需要 AudioClip；AudioListener 用于接收。

38. 关于 WaitForEndOfFrame，正确的是？
A. 在下一帧 Update 之后　B. 在下一次 FixedUpdate 之前　C. 在当前帧结束的瞬间恢复　D. 在当前帧所有渲染完成之后且在当前帧结束前恢复

  • 正确答案：D
  • 解析：WaitForEndOfFrame 在当前帧所有渲染完成后、帧结束前恢复，常用于截图。

39. 关于 ScriptableObject，正确的是？
A. 必须挂载在 GameObject 上　B. 是可序列化的数据容器资源　C. 只能作为资源加载而不支持运行时创建　D. 无法作为组件的字段进行序列化

  • 正确答案：B
  • 解析：ScriptableObject 是可序列化的数据容器资源，常用于配置，不依附 GameObject。

40. 关于 LayerMask，正确的是？
A. 以位掩码表示参与检测的 Layer　B. 仅用于设置渲染层级　C. 常用于在 Raycast/Physics 查询时将表示的层从结果中剔除　D. 只能用于 UI

  • 正确答案：A
  • 解析：LayerMask 以位掩码表示参与检测的 Layer，用于 Raycast/Physics 查询过滤。

41. 关于 Rigidbody 的 Interpolate，正确的是？
A. 开启后 Rigidbody 不再受到重力　B. 在固定物理更新与渲染帧之间平滑位置，减少抖动　C. 用于设置物理更新的次数　D. 用于开启连续碰撞检测

  • 正确答案：B
  • 解析：Rigidbody Interpolate 在固定物理更新与渲染帧之间平滑位置，减少抖动。

44. 关于 AddForce，正确的是？
A. 包括 Force、Acceleration、Impulse、VelocityChange 四种模式　B. 可以给 BodyType 为 Kinematic 的 Rigidbody 施加力（或冲量）　C. 不依赖于 Rigidbody 的激活状态　D. 表示力的参数是一个标量

  • 正确答案：A
  • 解析：AddForce 支持 Force/Acceleration/Impulse/VelocityChange 四种 ForceMode。

force 表示施加力的向量，描述力的大小和方向。

mode 表示应用力的效果的方式，包括 Force、Acceleration、Impulse、VelocityChange 四种模式。
Force：将 force 看作力（以牛顿为单位），计算公式为 (force∗deltTime)/mass，受 deltTime 和 mass 的影响。
Accelearation：将 force 看作加速度（以米每平方秒为单位），计算公式为 force*deltTime，受 deltTime 的影响。
Impulse：将 force 看作冲力（以牛顿为单位），计算公式为 force/mass，受 mass 的影响。
VelocityChange：将 force 看作速度变化值（以米每秒为单位），直接修改速度值。

注意： 该方法仅适用于附加了已激活的刚体的游戏对象，且刚体的类型不能为 Kinematic。当通过该方法施加力时刚体默认会被唤醒，除非 force 为零向量。

1.（简答）请说明 C# 中值类型与引用类型的主要区别（存储、赋值语义、继承、默认值等）。

标准答案：

值类型：局部变量在栈上，作为字段时内联在对象中；赋值复制值；不能继承类但可实现接口；默认 0/false。
引用类型：对象分配在托管堆，变量保存引用；赋值复制引用（两个变量指向同一对象）；支持继承与多态；默认 null。

7.（简答）请说明 C# 中 == 与 Equals 的区别。

标准答案：

== 是运算符，可在类型中重载；对于值类型比较值，对于引用类型默认比较引用（string 等重载后比较值）。
Equals 是 object 的虚方法，可被重写；static object.Equals(a,b) 会先做 null 判断再调用实例 Equals。
值类型重写 Equals 可避免装箱，自定义类型常同时重写 Equals 与 GetHashCode。

8.（简答）请说明 Resources.Load 的用法与缺点。

标准答案：

用法：Resources.Load<T>(path) 同步加载 Resources 目录下的资源，返回资源对象；配合 Instantiate 创建实例。
缺点：Resources 下资源会被全部打进包体、无法按需裁剪与增量管理，易造成包体膨胀；不便于热更新。建议使用 AssetBundle/Addressables 替代。

9.（简答）请说明 StringBuilder 与 string 拼接的区别与适用场景。

标准答案：

string 不可变，每次拼接都会生成新的字符串对象，频繁拼接会产生大量临时对象与 GC。
StringBuilder 内部维护可变缓冲，追加操作不产生新字符串，适合循环/大量拼接。
少量拼接直接用 string 或插值即可；StringBuilder 不是线程安全的。

10.（简答）请说明 UGUI 中 Canvas Scaler 的三种缩放模式。

标准答案：

Constant Pixel Size：UI 保持固定像素大小，不随分辨率缩放。
Scale With Screen Size：按参考分辨率等比缩放，最常用，可配合 Match 控制宽高权重。
Constant Physical Size：按物理尺寸（DPI）缩放，保持物理大小一致。

11.（简答）请说明 Time.deltaTime、Time.unscaledDeltaTime、Time.fixedDeltaTime 的区别。

标准答案：

Time.deltaTime：上一帧到当前帧的时间（受 timeScale 影响），Update 中做与帧率无关的移动。
Time.unscaledDeltaTime：不受 timeScale 影响的帧间隔，用于暂停时仍需更新的逻辑。
Time.fixedDeltaTime：固定物理步长（默认 0.02s），FixedUpdate 中的物理计算使用。
