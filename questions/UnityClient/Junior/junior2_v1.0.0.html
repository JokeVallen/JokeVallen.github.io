一、客观题

C# 基础

1. 关于 值类型与引用类型的赋值语义，正确的是？
A. 值类型赋值复制引用，引用类型赋值复制值　B. 值类型赋值复制值，引用类型赋值复制引用（两个变量指向同一对象）　C. 两者赋值都复制引用　D. 两者赋值都复制值

  • 正确答案：B
  • 解析：值类型赋值复制值，引用类型赋值复制引用（两个变量指向同一对象）

2. 关于 params 关键字，正确的是？
A. 只能用于引用类型参数　B. 调用时必须显式传入数组　C. 用于可变参数，调用时可直接传入离散元素，编译器自动打包为数组　D. 一个方法可以定义多个 params 参数

  • 正确答案：C
  • 解析：用于可变参数，调用时可直接传入离散元素，编译器自动打包为数组

3. 关于 可选参数与命名参数，正确的是？
A. 可选参数必须放在参数列表最前面　B. 可选参数必须位于必选参数之后；命名参数可打乱实参顺序　C. 命名参数不能与位置参数混用　D. 可选参数的默认值必须是变量

  • 正确答案：B
  • 解析：可选参数必须位于必选参数之后；命名参数可打乱实参顺序

4. 关于 方法重载与重写，正确的是？
A. 重载发生在父子类之间　B. 重载是同一类中方法名相同、参数列表不同；重写是子类用 override 改写父类虚方法　C. 重写发生在同一个类中　D. 重载要求方法签名完全相同

  • 正确答案：B
  • 解析：重载是同一类中方法名相同、参数列表不同；重写是子类用 override 改写父类虚方法

5. 关于 空合并 ?? 与空条件 ?.，正确的是？
A. a ?? b 在 a 不为 null 时返回 b　B. a ?? b 在 a 为 null 时返回 b；a?.b 在 a 为 null 时返回 null 不抛异常　C. a?.b 在 a 为 null 时抛异常　D. 两者只能用于值类型

  • 正确答案：B
  • 解析：a ?? b 在 a 为 null 时返回 b；a?.b 在 a 为 null 时返回 null 不抛异常

6. 关于 索引器，正确的是？
A. 索引器就是数组字段　B. 索引器只能返回 int　C. 用 this[int index] 形式定义，可用任意类型作索引　D. 一个类只能有一个索引器

  • 正确答案：C
  • 解析：用 this[int index] 形式定义，可用任意类型作索引

7. 关于 元组与解构，正确的是？
A. 元组只能包含两个元素　B. ValueTuple 是引用类型　C. (int x, int y) = (1, 2) 是解构赋值　D. 元组不能作为方法返回值

  • 正确答案：C
  • 解析：(int x, int y) = (1, 2) 是解构赋值

8. 关于 静态类与分部类，正确的是？

  • 正确答案：A
  • 解析：静态类只能包含静态成员、不能被继承；分部类用 partial 拆分到多个文件

A. Array 长度固定，List<T> 可动态扩容　B. List<T> 长度固定　C. Array 长度可变　D. List<T> 不能索引访问

  • 解析：Array 长度固定，List<T> 可动态扩容

10. 关于 C# 扩展方法，正确的是？
A. 可以重写被扩展类型的现有方法　B. 必须定义在实例类中　C. 可以访问被扩展类型的私有成员　D. 定义在静态类中的静态方法，第一个参数前加 this，可像实例方法一样调用

1.（简答）请说明 C# 中值类型与引用类型的主要区别（存储、赋值语义、继承、默认值等）。

标准答案：

值类型：局部变量在栈上，作为字段时内联在对象中；赋值复制值；不能继承类但可实现接口；默认 0/false。
引用类型：对象分配在托管堆，变量保存引用；赋值复制引用（两个变量指向同一对象）；支持继承与多态；默认 null。

7.（简答）请说明 C# 中 == 与 Equals 的区别。

标准答案：

== 是运算符，可在类型中重载；对于值类型比较值，对于引用类型默认比较引用（string 等重载后比较值）。
Equals 是 object 的虚方法，可被重写；static object.Equals(a,b) 会先做 null 判断再调用实例 Equals。
值类型重写 Equals 可避免装箱，自定义类型常同时重写 Equals 与 GetHashCode。

8.（简答）请说明 Resources.Load 的用法与缺点。

标准答案：

用法：Resources.Load<T>(path) 同步加载 Resources 目录下的资源，返回资源对象；配合 Instantiate 创建实例。
缺点：Resources 下资源会被全部打进包体、无法按需裁剪与增量管理，易造成包体膨胀；不便于热更新。建议使用 AssetBundle/Addressables 替代。

9.（简答）请说明 StringBuilder 与 string 拼接的区别与适用场景。

标准答案：

string 不可变，每次拼接都会生成新的字符串对象，频繁拼接会产生大量临时对象与 GC。
StringBuilder 内部维护可变缓冲，追加操作不产生新字符串，适合循环/大量拼接。
少量拼接直接用 string 或插值即可；StringBuilder 不是线程安全的。

10.（简答）请说明 UGUI 中 Canvas Scaler 的三种缩放模式。

标准答案：

Constant Pixel Size：UI 保持固定像素大小，不随分辨率缩放。
Scale With Screen Size：按参考分辨率等比缩放，最常用，可配合 Match 控制宽高权重。
Constant Physical Size：按物理尺寸（DPI）缩放，保持物理大小一致。

11.（简答）请说明 Time.deltaTime、Time.unscaledDeltaTime、Time.fixedDeltaTime 的区别。

标准答案：

Time.deltaTime：上一帧到当前帧的时间（受 timeScale 影响），Update 中做与帧率无关的移动。
Time.unscaledDeltaTime：不受 timeScale 影响的帧间隔，用于暂停时仍需更新的逻辑。
Time.fixedDeltaTime：固定物理步长（默认 0.02s），FixedUpdate 中的物理计算使用。
