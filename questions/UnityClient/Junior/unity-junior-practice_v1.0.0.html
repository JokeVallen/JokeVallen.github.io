一、客观题

1. C# 中 int 的默认值是？

A常量 1
B零值 0
C空引用 null
D随机整数值
查看答案与解析

正确答案：B

值类型字段默认初始化为零值，int 为 0。

反馈本题

2. 关于 var 关键字，说法正确的是？

A运行时的动态类型推断
B完全等价于 object 类型
C类型由编译器推断
D声明时可以省略初始化赋值
查看答案与解析

正确答案：C

var 是隐式类型局部变量，编译期即确定具体类型。

反馈本题

3. 数组长度不足时下标访问越界，会抛出？

ANullReferenceException
BInvalidCastException
CFormatException
DIndexOutOfRangeException
查看答案与解析

正确答案：D

下标超出数组范围会抛出 IndexOutOfRangeException。

反馈本题

4. 关于 const 与 readonly，区别是？

A二者语义完全相同可互换使用
Bconst 编译期常量，readonly 运行期赋值
Creadonly 只能修饰字符串类型
Dconst 可以在运行时动态赋值
查看答案与解析

正确答案：B

const 在编译期替换，readonly 可在构造期赋值，语义不同。

反馈本题

5. 遍历 Dictionary 时，推荐的方式是？

A按整数索引下标顺序访问
B直接强制转换为基础数组
C用 foreach 遍历 KeyValuePair
D用 while 循环递增 key 再取值
查看答案与解析

正确答案：C

Dictionary 无序，遍历应使用 KeyValuePair 的 foreach。

反馈本题

6. 关于 string 拼接，说法正确的是？

A原地修改原字符串内存块
B完全不占用托管堆内存
C编译器自动合并为常量
D每次 + 都可能产生新对象
查看答案与解析

正确答案：D

string 不可变，连续拼接会产生多个中间对象，频繁场景应用 StringBuilder。

反馈本题

7. int 与 object 之间的转换称为？

A对象序列化
B装箱与拆箱
C反射机制调用
D委托事件绑定
查看答案与解析

正确答案：B

值类型转 object 是装箱，反向是拆箱，都会带来开销。

反馈本题

8. 关于 foreach 循环中修改集合，通常会发生什么？

A枚举器会自动跳过之后插入的项且不报错
B对遍历结果完全没有任何影响
C可能抛出无效操作异常
D集合会自动重新排序并保持索引有效
查看答案与解析

正确答案：C

枚举期间修改集合会使枚举器失效并抛出异常。

反馈本题

9. 静态字段的生命周期通常是？

A每次方法调用重建
B随对象销毁释放
C只存在于编辑器
D随类型加载存在
查看答案与解析

正确答案：D

静态成员依附类型，生命周期通常长于实例，滥用易导致状态残留。

反馈本题

10. 关于 try/catch 的使用，较合理的做法是？

A包裹所有代码以防报错
B用于处理可预期失败并记录上下文
C完全不用异常
D只在 UI 层使用
查看答案与解析

正确答案：B

异常用于处理异常路径，应捕获具体类型并避免吞掉错误。

反馈本题

11. Unity 中打印调试信息最常用的接口是？

AConsole.Main 控制台
Bprint.All 全局打印
CDebug.Log 调试输出
DLog.Output 输出类
查看答案与解析

正确答案：C

Debug.Log 输出到 Console 与日志文件，适合排查。

反馈本题

12. 在 Unity 中查看某个对象的组件列表，最直接的位置是？

AProject 资源面板
BConsole 控制台面板
CProfiler 性能面板
DInspector 检视面板
查看答案与解析

正确答案：D

Inspector 展示选中对象的组件与序列化字段。

反馈本题

13. 关于 Prefab 实例与原始 Prefab，下列说法不正确的是？

A实例可覆盖原始 Prefab 的部分属性
B实例修改会自动反向同步到原始 Prefab
C可通过 Apply 把覆盖项回写原始 Prefab
D可通过 Revert 丢弃实例上的覆盖项
查看答案与解析

正确答案：B

实例可保存覆盖项，Apply 或 Revert 决定是否回写原始 Prefab。

反馈本题

14. 想在场景中快速对齐物体，常用快捷键是？

ACtrl + Z 撤销上一步操作
BCtrl + S 保存当前场景
CCtrl/Cmd + Shift + F
DCtrl + P 进入播放模式
查看答案与解析

正确答案：C

Ctrl/Cmd + Shift + F 让所选对象对齐到 Scene 视图视角。

反馈本题

15. 关于 Collider 与 Rigidbody，说法正确的是？

ACollider 必须同时挂载 Rigidbody 才能生效
BRigidbody 只能用于 UI 元素
C二者互不相关可完全独立配置
D至少一方带 Rigidbody 才能触发物理事件
查看答案与解析

正确答案：D

物理与触发检测需要运动方带 Rigidbody，Collider 提供形状。

反馈本题

16. 关于 OnCollisionEnter 与 OnTriggerEnter 的区别，正确的是？

A两者完全等同可以互换使用
B前者需要实体碰撞，后者需要 isTrigger
C前者只能用于 UI 交互事件
D后者完全不需要任何 Collider
查看答案与解析

正确答案：B

碰撞回调要求实体接触，触发回调要求 Collider 勾选 isTrigger。

反馈本题

17. 想在 Inspector 中直接调整公有字段，字段应？

A声明为 static 静态字段
B声明为 readonly 只读字段
C声明为公有或序列化
D声明为 const 常量字段
查看答案与解析

正确答案：C

只有可序列化字段会显示在面板，public 与 SerializeField 均满足。

反馈本题

18. 关于 List<T> 与数组，说法正确的是？

A数组支持动态扩容
BList 不能查询 Count
C数组不支持索引
DList 支持动态扩容
查看答案与解析

正确答案：D

List 内部使用数组并在容量不足时扩容，数组长度固定。

反馈本题

19. 关于枚举（enum）的默认底层类型是？

A字符串 string
B整型 int
C布尔 bool
D双精度 double
查看答案与解析

正确答案：B

未指定时枚举底层类型为 int，可显式指定其他整型。

反馈本题

20. 初始化大量对象频繁 GC，较合理的入门优化是？

A每帧强制 GC
B增加更多对象
C使用对象池复用
D关闭所有日志
查看答案与解析

正确答案：C

对象池可减少频繁分配与回收，是常见的入门级优化手段。

反馈本题

21. 关于 Debug.DrawLine，正确说法是？

A会在场景中生成永久网格
B会改变物体的物理碰撞形状
C需要在打包时生成额外资源
D只在 Scene/Game 视图可视化
查看答案与解析

正确答案：D

DrawLine 用于调试可视化，不影响游戏逻辑与构建资源。

反馈本题

22. 关于命名空间 using，说法正确的是？

A会自动加载对应的程序集
B引入类型可见性不改变程序集依赖
C效果等同于类型继承
D用于执行运行时的反射调用
查看答案与解析

正确答案：B

using 只简化类型引用写法，新增依赖仍需引用程序集/asmdef。

反馈本题

23. 关于 Time.time 与 Time.deltaTime，说法正确的是？

A两者含义完全相同可替换
B前者表示当前帧的间隔
C前者为累计时间，后者为帧间隔
D后者表示固定的物理步长
查看答案与解析

正确答案：C

Time.time 是自启动以来的累计时间，deltaTime 是两帧间隔。

反馈本题

24. 想在按下空格时触发一次跳跃，较合理的输入检测是？

AInput.GetKey(KeyCode.Space) 每帧跳跃
BInput.GetMouseButton(0)
CInput.anyKey
DInput.GetKeyDown(KeyCode.Space)
查看答案与解析

正确答案：D

GetKeyDown 只在按下那一帧返回 true，避免连续触发。

反馈本题

25. 关于 Canvas 渲染模式为 Screen Space - Overlay 时，正确的是？

A会被 3D 物体遮挡
B始终绘制在场景之上
C必须配合相机
D只支持世界坐标
查看答案与解析

正确答案：B

Overlay 模式不依赖相机，直接叠加在屏幕最上层。

反馈本题

26. 想在代码中查找子物体，较稳妥的做法是？

A每帧调用 Find 遍历
B反射遍历私有字段
C查一次并缓存引用
D依赖对象名硬编码
查看答案与解析

正确答案：C

缓存查找到的引用避免重复遍历，减少开销与耦合。

反馈本题

27. 关于协程 yield return null，含义是？

A立即结束协程
B等待 1 秒
C等待固定步长
D下一帧继续执行
查看答案与解析

正确答案：D

yield return null 在下一次 Update 后恢复执行。

反馈本题

28. 关于 Unity 项目里的 .meta 文件，说法正确的是？

A可以随意删除后自动重建
B记录资源 GUID 与导入设置
C只用于保存编辑器配色方案
D是构建时生成的编译产物
查看答案与解析

正确答案：B

meta 保存 GUID 与导入设置，删除会导致引用丢失，需提交版本库。

反馈本题

29. 关于 transform.position 与 transform.localPosition，说法正确的是？

A两者在任何情况下总是相同
B前者是相对父物体的坐标
C前者相对世界，后者相对父物体
D后者只能用于 UI 元素定位
查看答案与解析

正确答案：C

position 是世界坐标，localPosition 是相对父节点的局部坐标。

反馈本题

30. 初学者排查"物体不显示"，最不该做的是？

A检查激活状态与 Layer
B检查相机裁剪与位置
C检查材质与渲染器
D直接重装编辑器
查看答案与解析

正确答案：D

应先从激活状态、层掩码、相机与渲染器逐项排查，重装环境通常无效。
