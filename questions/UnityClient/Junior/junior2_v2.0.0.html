一、客观题

C# 基础

1. 以下引用类型赋值后，输出是？

A. 20　B. 10　C. 0　D. 编译错误

  • 正确答案：A
  • 解析：Wrapper 是引用类型，b = a 复制的是引用，两个变量指向同一个对象，修改 b.P.X 也会影响 a.P.X。

2. 用 ArrayList 存放大量 int 时，相比 List<int> 的主要劣势是？
A. ArrayList 不能存 int　B. 存取每个 int 都会装箱拆箱　C. ArrayList 长度固定　D. ArrayList 不能遍历

  • 正确答案：B
  • 解析：ArrayList 以 object 存储元素，int 存取时发生装箱/拆箱；List<int> 是强类型泛型集合，避免装箱并能在编译期检查类型。

3. 在循环中拼接字符串，每轮都执行 s = s + i，主要问题是？
A. 无法编译　B. string 会被自动装箱　C. 每次都产生新的字符串对象　D. 会改变原字符串内容

  • 正确答案：C
  • 解析：string 不可变，每次 + 都生成新字符串；大量拼接应使用 StringBuilder，避免频繁分配。

4. 判断两个字符串内容是否相等，下面哪种做法最容易误判？
A. string.Equals(a, b, StringComparison.Ordinal)　B. a == b　C. ReferenceEquals(a, b)　D. string.Compare(a, b, StringComparison.Ordinal) == 0

  • 正确答案：C
  • 解析：ReferenceEquals 比较引用地址；即使内容相同，运行时生成的两个字符串也可能是不同对象，因此会误判。

5. 需要表达一个固定 3 个分量的轻量数据类型，实例数量多且不涉及继承，较适合的是？
A. interface　B. class　C. struct　D. abstract class

  • 正确答案：C
  • 解析：struct 是值类型，适合小、短生命周期、无继承需求的数据；class 有对象头与堆分配开销，interface/abstract class 不用于数据载体。

6. 下列泛型约束中，能让方法内安全使用 new T() 的是？
A. where T : class　B. where T : IDisposable　C. where T : struct　D. where T : new()

  • 正确答案：D
  • 解析：new() 约束保证 T 具有公共无参构造函数，方法内才能 new T()。class 只保证引用类型，struct 保证值类型，都不保证构造函数签名。

7. 需要按学生学号快速查找学生信息，学号唯一且数量较大，最合适的结构是？
A. Dictionary 按键快速查找　B. Queue 按入队顺序查找　C. List 配合遍历，按顺序查找　D. Stack 按出栈顺序查找

  • 正确答案：A
  • 解析：Dictionary 按键查找平均 O(1)，适合唯一键的快速检索；List 遍历是 O(n)，Queue/Stack 只适合特定顺序访问。

8. 遍历 List<int> 的过程中调用 Add，通常会发生什么？
A. 自动转为 for 循环继续　B. 抛出 InvalidOperationException　C. Add 被静默忽略　D. 新元素被安全插入并继续遍历

  • 正确答案：B
  • 解析：List 的枚举器带版本校验，遍历中增删都会抛 InvalidOperationException；应改用 for 或先收集再修改。

9. 事件有多个订阅者，其中一个订阅者抛出未捕获异常，默认结果是？
A. 中断后续订阅者的调用　B. 自动回滚已经执行过的回调　C. 异常被事件系统静默忽略　D. 所有订阅者都会照常执行

  • 正确答案：A
  • 解析：默认的委托调用链遇到异常会中断，后续订阅者不再收到通知；健壮的事件中心应逐个 try/catch 或使用 GetInvocationList。

10. 以下代码依次执行三个委托，输出是？

A. 0 1 2　B. 1 2 3　C. 3 3 3　D. 0 0 0

  • 正确答案：C
  • 解析：for 的循环变量只有一个，三个闭包捕获同一个变量；循环结束后 i 为 3，因此输出 3 3 3。

11. 在方法中打开文件流，且读取过程可能抛出异常，使用 using 的关键收益是？
A. 只能用于文件流　B. 发生了异常就不会调用 Dispose　C. 必须配合 try/catch 才能使用　D. 离开作用域或发生异常时都会调用 Dispose

  • 正确答案：D
  • 解析：using 编译为 try/finally，保证 Dispose 一定调用；任何实现 IDisposable 的类型都可用。

12. 当 s 为 null 时，表达式 s?.Length ?? -1 的结果是？
A. 抛 NullReferenceException　B. -1　C. 0　D. 编译错误

  • 正确答案：B
  • 解析：?. 在 s 为 null 时返回可空的 null，?? 再取右值 -1，因此不会抛异常。

13. 自动属性 public int HP { get; init; } 的特点是？
A. 外部可以随时读写 HP　B. 只能在对象初始化时赋值，之后只读　C. 只能在声明类型内部赋值　D. 等价于普通公共字段

  • 正确答案：B
  • 解析：init 访问器允许在对象初始化器或构造函数中赋值，初始化完成后属性只读；它适合表达不可变数据。

14. C# 的 in 参数与 ref 参数的主要区别是？
A. in 是值传递，ref 是引用传递　B. 两者完全等价，可互相替换　C. ref 只能用于值类型参数　D. in 按引用传入但方法内只读，ref 可读写

  • 正确答案：D
  • 解析：in 传递只读引用，适合较大的结构体以避免复制；ref 允许方法内读写调用方变量。二者都不允许在方法内重新绑定引用本身。

15. C# 中 static 字段与实例字段的主要区别是？
A. 两者完全等价，只是访问方式不同　B. static 字段属于对象，实例字段属于类型　C. static 字段属于类型，实例字段属于对象　D. static 字段不能被序列化

  • 正确答案：C
  • 解析：static 字段在类型级别共享，所有实例看到同一份；实例字段每个对象各自持有。

16. C# 命名参数与可选参数的作用是？
A. 命名参数会改变方法签名　B. 两者都只能用于构造函数　C. 命名参数可打乱实参顺序，可选参数可省略　D. 可选参数必须放在参数列表最前面

  • 正确答案：C
  • 解析：命名参数按名字匹配，允许跳过或打乱顺序；可选参数带默认值，调用时可省略。可选参数必须位于必选参数之后。

17. C# 异常过滤器 catch (Exception e) when (cond) 的特点是？
A. cond 在 catch 执行之后才判断　B. 只有 cond 为 true 时才进入该 catch　C. when 只能用于 finally 块　D. when 会吞掉所有类型的异常

  • 正确答案：B
  • 解析：异常过滤器在进入 catch 前求值，条件不满足时会继续匹配后续 catch；它不会改变异常传播栈。

18. 关于索引器，下列说法正确的是？
A. 索引器就是数组字段　B. 索引器不能被外部访问　C. 索引参数类型只能是 int　D. 一个类可以有多个参数列表不同的索引器

  • 正确答案：D
  • 解析：索引器本质是带参数的属性，可使用 string、int 等不同类型；同一个类可以重载多个索引器，外部通过 obj[key] 访问。

19. 类型第一次被使用前，静态构造函数会执行几次？
A. 一次　B. 每次创建实例时一次　C. 每次访问静态成员时一次　D. 不确定，由运行时决定

  • 正确答案：A
  • 解析：静态构造函数由 CLR 在类型首次使用前自动调用且仅调用一次；它不能显式调用，也不能带参数。

20. 关于扩展方法，下列说法正确的是？
A. 必须定义在静态类中　B. 只能在同一个程序集中使用　C. 可以访问被扩展类型的私有成员　D. 可以覆盖被扩展类型的原有实例方法

  • 正确答案：A
  • 解析：扩展方法定义在静态类中，第一个参数使用 this；它不能覆盖实例方法，也不能访问私有成员。实例方法优先于同名扩展方法。

21. 重载 == 运算符时，通常还必须重载哪个运算符？
A. +　B. !=　C. =　D. []

  • 正确答案：B
  • 解析：C# 要求 == 与 != 成对重载；否则编译器会报错。重写 == 时还应同步重写 Equals 与 GetHashCode，保持语义一致。

22. 关于可空值类型 int?，下列说法正确的是？
A. int? 是引用类型　B. int? 装箱后仍是 int?　C. int? 不能参与运算　D. int? 可以赋值为 null

  • 正确答案：D
  • 解析：int? 是 Nullable<int> 的语法糖，属于值类型，可表示 null；有值时可通过 Value 访问，装箱时若为 null 则得到空引用。

23. 关于 nameof 运算符，下列说法正确的是？
A. 通过反射在运行时获取名称　B. 在编译期确定　C. 每次调用都返回新字符串　D. 只能用于字段

  • 正确答案：B
  • 解析：nameof 在编译期求出符号名称，适合替代硬编码字符串，能避免拼写错误且没有反射开销；它可用于变量、属性、方法、类型等。

24. 关于 C# 的 checked 与 unchecked，下列说法正确的是？
A. unchecked 会关闭整型溢出检查　B. checked 会改变变量类型　C. 两者只影响浮点数　D. 默认对整型运算开启溢出检查

  • 正确答案：A
  • 解析：C# 默认是 unchecked，整型溢出会回绕；checked 开启检查并抛 OverflowException。二者都不影响浮点数。

25. 自定义类型要实现默认排序规则，应实现哪个接口？
A. IEnumerable<T>　B. IComparable<T>　C. IDisposable　D. ICloneable

  • 正确答案：B
  • 解析：IComparable<T> 提供 CompareTo，让类型自身具备默认比较规则；多种外部排序规则则用 IComparer<T> 传入 Sort。

26. 数组和 List<T> 的典型区别是？
A. 数组只能存值类型　B. List<T> 不能按下标访问　C. 数组长度固定　D. 数组不能遍历

  • 正确答案：C
  • 解析：数组长度创建后固定；List<T> 内部维护可扩容数组，支持 Add/Remove 与下标访问，是更常用的动态集合。

27. 类中有一个 Lambda 每次调用都捕获局部变量并返回委托，主要可能带来什么开销？
A. 编译错误，闭包无法捕获局部变量　B. 会把捕获的变量自动装箱到堆上　C. 没有任何开销，闭包会被编译器内联　D. 闭包会生成显示类实例并分配到堆上

  • 正确答案：D
  • 解析：闭包捕获外部变量时，编译器会生成一个类来保存这些变量，其实例分配在堆上；热路径中应缓存委托或避免闭包捕获。

Unity 引擎基础

28. 对象被 SetActive(false) 后再 SetActive(true)，哪个回调会再次触发？
A. OnEnable 会再次触发，Awake 不会　B. Awake 会再次触发，OnEnable 不会　C. 两者都会再次触发　D. 两者都不会再次触发

  • 正确答案：A
  • 解析：Awake 只在实例首次激活时执行一次；重新激活会再次调用 OnEnable，但不会重复调用 Awake 和 Start。

29. OnEnable 会在哪些情况下被调用？
A. 只在 Start 之前调用一次　B. 只在对象第一次被创建时调用一次　C. 只在对象被销毁时调用　D. 对象首次激活以及每次重新激活时

  • 正确答案：D
  • 解析：OnEnable 在对象激活时调用，且每次重新激活都会再次触发；Awake/Start 只在首次激活流程中执行。

30. 物理相关逻辑应优先放在哪个回调中？
A. FixedUpdate　B. Update　C. LateUpdate　D. OnGUI

  • 正确答案：A
  • 解析：FixedUpdate 按固定时间步调用，与物理系统一致；在其中处理刚体受力、MovePosition 等物理逻辑，能避免帧率波动影响。

31. Time.unscaledDeltaTime 的用途是？
A. 获取不受 timeScale 影响的帧间隔　B. 获取固定物理步长　C. 获取自游戏开始的总时间　D. 获取当前目标帧率

  • 正确答案：A
  • 解析：unscaledDeltaTime 不随 timeScale 缩放，适合暂停界面动画、计时器等需要真实帧间隔的场景。

32. 相机跟随角色时，较推荐放在哪个回调中？
A. FixedUpdate　B. LateUpdate　C. Awake　D. OnEnable

  • 正确答案：B
  • 解析：LateUpdate 在所有 Update 之后执行，能保证角色本帧移动完成后再更新相机，避免相机抖动或滞后一帧。

33. 协程中 yield return null 会在什么时候恢复执行？
A. 当前帧渲染结束之后　B. 当前帧 FixedUpdate 之前　C. 下一帧 Update 之后　D. 下一帧 Start 之前

  • 正确答案：C
  • 解析：yield return null 让协程在下一帧的 Update 阶段之后继续；要等到渲染结束用 WaitForEndOfFrame。

34. WaitForEndOfFrame 与 WaitForFixedUpdate 的恢复时机分别是？
A. 渲染完成后 / 下一次 FixedUpdate 之前　B. 下一次 FixedUpdate 之前 / 渲染完成后　C. 两者都在下一帧 Update 之后　D. 两者都在物理步之前

  • 正确答案：A
  • 解析：WaitForEndOfFrame 在当前帧渲染结束后恢复，适合截图；WaitForFixedUpdate 在下一次物理步前恢复。

35. DestroyImmediate 与 Destroy 的主要区别是？
A. DestroyImmediate 只能销毁资源对象　B. DestroyImmediate 立即销毁，Destroy 延迟到帧末　C. 两者完全等价，只是命名不同　D. Destroy 不能销毁 GameObject

  • 正确答案：B
  • 解析：Destroy 在当前帧 Update 之后执行，DestroyImmediate 立即执行；后者会打断遍历等操作，通常只建议在编辑器代码中使用。

36. SetParent(parent, true) 与 SetParent(parent, false) 的区别是？
A. false 会删除父子关系　B. true 保持 local 变换，false 保持世界坐标　C. true 保持世界坐标，false 保持 local 变换　D. 两者完全等价

  • 正确答案：C
  • 解析：worldPositionStays 为 true 时会反算 local 变换以维持世界坐标；为 false 时保留原 local 变换，世界坐标随父级改变。

37. 父物体缩放为 (2,2,2) 时，子物体的 transform.localScale 与 lossyScale 的关系是？
A. localScale 相对父级，lossyScale 是世界空间等效缩放　B. 两者永远相等，与父级缩放无关　C. localScale 是世界缩放，lossyScale 相对父级　D. lossyScale 只对 UI 元素有意义

  • 正确答案：A
  • 解析：localScale 是相对父级的缩放；lossyScale 是考虑父级缩放后的世界空间等效缩放，父级非均匀缩放时两者不相等。

38. OnTriggerExit 在什么时候触发？
A. 碰撞体刚进入触发器时　B. 触发器被销毁时　C. 两个碰撞体发生物理碰撞时　D. 碰撞体离开触发器区域时

  • 正确答案：D

39. 想给刚体施加一个持续力，较合适的做法是？

105. 在数组中间插入一个元素，时间复杂度是？

  • 正确答案：B
  • 解析：链表在已知节点位置时插入/删除 O(1)，不需要连续内存；随机访问需从头遍历，因此适合不要求随机访问、频繁增删的场景。

109. 哈希冲突严重、桶内退化为链表时，哈希表的最坏查找复杂度是？
