一、客观题

C# 基础

1. 关于 yield break，正确的是？
A. 结束整个程序　B. 跳出当前 for/while 循环　C. 与 break 完全等价　D. 用于提前结束迭代器

  • 正确答案：D
  • 解析：用于提前结束迭代器

2. 关于闭包捕获变量，正确的是？
A. 捕获的是变量在捕获瞬间的副本　B. 闭包不能捕获引用类型　C. 捕获的是变量本身，外部修改后闭包内也能看到新值　D. 闭包捕获变量会导致编译错误

  • 正确答案：C
  • 解析：捕获的是变量本身，外部修改后闭包内也能看到新值

3. 关于泛型约束 where T : class，正确的是？
A. 要求 T 必须是值类型　B. 要求 T 必须有无参构造函数　C. 要求 T 必须实现 IDisposable　D. 要求 T 必须是引用类型

  • 正确答案：D
  • 解析：要求 T 必须是引用类型

4. 关于 foreach 的本质，正确的是？
A. 直接按下标访问集合元素　B. 调用 GetEnumerator()，循环 MoveNext() 并读取 Current　C. 必须实现 IList 才能 foreach　D. foreach 会自动复制整个集合

  • 正确答案：B
  • 解析：调用 GetEnumerator()，循环 MoveNext() 并读取 Current

5. 扩展方法与实例方法同名同签名时，调用哪个？
A. 扩展方法优先　B. 编译错误　C. 随机选择其一　D. 实例方法优先，扩展方法不会被调用

  • 正确答案：D
  • 解析：实例方法优先，扩展方法不会被调用

6. 关于静态字段初始化器与静态构造函数的执行顺序，正确的是？
A. 静态构造函数先执行　B. 静态字段初始化器按声明顺序执行，静态构造函数在其后执行　C. 两者交替执行　D. 顺序不确定

  • 正确答案：B
  • 解析：静态字段初始化器按声明顺序执行，静态构造函数在其后执行

7. IComparable 与 IComparer 在排序中的分工是？
A. 两者都由元素自身实现　B. IComparable 由元素自身实现，IComparer 作为外部比较器传入 Sort　C. IComparer 由元素自身实现　D. 两者只能用于相等性比较

  • 正确答案：B
  • 解析：IComparable 由元素自身实现，IComparer 作为外部比较器传入 Sort

8. 关于 async/await，正确的是？
A. async 方法一定在新线程上执行　B. await 只能用于同步方法　C. async 方法通常返回 Task/Task<T>，await 用于等待异步操作完成　D. async 方法不能有返回值

  • 正确答案：C
  • 解析：async 方法通常返回 Task/Task<T>，await 用于等待异步操作完成

9. 派生类实例化时，字段初始化器与构造函数的执行顺序是？
A. 基类构造函数 → 派生类字段初始化器 → 派生类构造函数　B. 派生类构造函数 → 基类构造函数 → 字段初始化器　C. 派生类字段初始化器 → 基类字段初始化器 → 基类构造函数 → 派生类构造函数体　D. 顺序由运行时决定

  • 正确答案：C
  • 解析：派生类字段初始化器 → 基类字段初始化器 → 基类构造函数 → 派生类构造函数体

10. 重载 == 运算符时，为什么通常必须同时重载 !=？
A. 否则会运行时报错　B. 为了提升性能　C. 没有强制要求　D. C# 要求 == 与 != 必须成对重载

  • 正确答案：D
  • 解析：C# 要求 == 与 != 必须成对重载

11. dynamic 与 object 的核心区别是？
A. 两者完全等价　B. dynamic 是值类型　C. dynamic 跳过编译期类型检查、运行时解析；object 需要显式转换　D. object 只能存放值类型

  • 正确答案：C
  • 解析：dynamic 跳过编译期类型检查、运行时解析；object 需要显式转换

12. switch 模式匹配中 when 子句的作用是？
A. 指定模式优先级　B. 在模式匹配成功的基础上附加额外条件　C. 用于类型转换　D. 用于捕获异常

  • 正确答案：B
  • 解析：在模式匹配成功的基础上附加额外条件

13. 关于 协变与逆变，正确的是？
A. 逆变允许把 IEnumerable<object> 赋给 IEnumerable<string>　B. 泛型接口默认支持协变与逆变　C. 协变与逆变只用于委托　D. 协变允许把 IEnumerable<string> 赋给 IEnumerable<object>

  • 正确答案：D
  • 解析：协变允许把 IEnumerable<string> 赋给 IEnumerable<object>

14. 关于 反射，正确的是？
A. 只能获取字段，不能调用方法　B. 反射比直接调用更高效　C. 可在运行时获取类型信息、创建实例、调用方法，但有一定性能开销　D. 只能用于编辑器，运行时不可用

  • 正确答案：C
  • 解析：可在运行时获取类型信息、创建实例、调用方法，但有一定性能开销

15. 如何限制自定义特性只能用于类？
A. 在特性类名加 Class 后缀　B. 实现 IClassAttribute 接口　C. 用 [AttributeUsage(AttributeTargets.Class)] 限定　D. 无法限制

  • 正确答案：C
  • 解析：用 [AttributeUsage(AttributeTargets.Class)] 限定

16. 关于 弱引用 WeakReference，正确的是？
A. 持有强引用，阻止 GC 回收　B. 会导致目标对象立即被回收　C. 不阻止 GC 回收目标，可用于缓存　D. 只能用于值类型

  • 正确答案：C
  • 解析：不阻止 GC 回收目标，可用于缓存

17. 如何判断一个 [Flags] 枚举变量 value 是否包含标志 flag？
A. value | flag　B. value == flag　C. (value & flag) == flag　D. value ^ flag

  • 正确答案：C
  • 解析：(value & flag) == flag

18. C# 默认（未显式指定）时，整型运算溢出会怎样？
A. 默认为 unchecked，溢出回绕不报错　B. 默认抛 OverflowException　C. 编译期直接报错　D. 自动提升为 long 避免溢出

  • 正确答案：A
  • 解析：默认为 unchecked，溢出回绕不报错

19. int[][] 与 int[,] 在内存布局上的区别是？
A. int[][] 是数组的数组（各行独立），int[,] 是连续矩形数组　B. 两者布局完全相同　C. int[,] 是交错数组　D. int[][] 是连续矩形数组

  • 正确答案：A
  • 解析：int[][] 是数组的数组（各行独立），int[,] 是连续矩形数组

20. 关于 字符串驻留，正确的是？
A. 相同字面量字符串通常指向同一驻留实例　B. 所有字符串都会自动驻留　C. 驻留会增加内存　D. string.Intern 用于释放字符串

  • 正确答案：A

40. UGUI 中，什么操作会触发布局重建（Rebuild）？

41. 关于 Canvas 重建（Rebuild），正确的是？

  • 正确答案：C
  • 解析：Canvas 在 WillRenderCanvases 阶段统一重建；拆分 Canvas 可减少重建与合批影响范围。

二、主观题

1.（简答）请说明协程与 Invoke 的区别，以及常见 yield 指令（yield return null、WaitForSeconds、WaitForFixedUpdate、WaitForEndOfFrame）的恢复时机。

标准答案：

Invoke：按延迟调用方法（一次或重复），不能跨帧暂停、不能带参数、不能暂停/恢复。
协程：返回 IEnumerator，由 Unity 调度，可跨帧、可带参、可暂停/恢复/停止，控制更灵活。
常见 yield 指令的恢复时机：

  • yield return null：下一帧 Update 之后；
  • WaitForSeconds：缩放时间到达后；
  • WaitForSecondsRealtime：真实时间到达后；
  • WaitForFixedUpdate：下一次 FixedUpdate 之前；
  • WaitForEndOfFrame：当前帧渲染完成之后。

2.（简答）请说明 Unity 中 MonoBehaviour 单例的实现方式，以及跨场景保留、防止重复实例时需要注意什么。

标准答案：

实现：静态 Instance 字段 + Awake 中判空赋值，重复实例销毁；跨场景可 DontDestroyOnLoad。
注意事项：

  • 切换场景默认销毁对象，需要 DontDestroyOnLoad；
  • 重复进入场景会创建多个实例，需判重销毁；
  • 播放模式退出/域重载时静态字段可能残留，应在 OnDestroy 清理；
  • 不要在 OnDestroy 中访问可能已销毁的其他对象。

3.（简答）请说明对象池的适用场景，以及实现时必须处理的关键问题。

标准答案：

适用场景：频繁创建/销毁且状态可复用的对象（子弹、特效、列表项）。
关键问题：

  • 回收时重置状态，避免取出“脏对象”；
  • 设置池上限，避免内存只增不减；
  • 取出与回收必须成对，避免泄漏；
  • 必要时考虑线程安全与多池分类管理。

4.（简答）请说明 ScriptableObject 的用途与优势，以及它与 MonoBehaviour 的区别。

标准答案：

用途：以资源形式存储可序列化的共享数据，如配置表、游戏参数、技能数据。
优势：

  • 不依附 GameObject，可被多个对象引用，节省内存；
  • 可在 Inspector 编辑，可作为资源热更；
  • 适合数据驱动设计。
    区别：MonoBehaviour 必须挂载在 GameObject 上并参与帧循环；ScriptableObject 是纯数据资产。

5.（简答）请说明 C# 迭代器（yield）的状态机原理，以及它与“返回数组”在内存与执行时机上的差异。

标准答案：

编译器会把含 yield 的方法编译成一个状态机类，保存执行位置与局部变量。
调用方法时不会立即执行方法体；每次 MoveNext() 才推进到下一个 yield 并暂停。
与返回数组相比：

  • 迭代器惰性计算，额外空间 O(1)，适合大数据流；
  • 返回数组一次性计算，需要 O(n) 空间。

6.（简答）请说明观察者/事件系统的优点与常见坑，并给出一个健壮事件中心的设计要点。

标准答案：

优点：一对多通知、发布者与订阅者解耦、易于扩展。
常见坑：

  • 忘记退订导致内存泄漏/悬挂引用；
  • 回调中增删监听者导致遍历异常（应先复制一份再触发）；
  • 某个监听者抛异常会中断后续监听者（可逐个 try/catch）；
  • 事件顺序不保证，避免依赖顺序。

7.（简答）请说明 LOD、遮挡剔除（Occlusion Culling）、视锥剔除（Frustum Culling）三者的区别与作用。

标准答案：

视锥剔除：剔除不在相机视锥体内的物体，Unity 默认开启。
遮挡剔除：剔除被其他物体挡住、不可见的物体，需烘焙。
LOD：根据物体与相机距离切换不同精度模型，降低远距离渲染开销。三者都是减少渲染量的优化手段。

8.（简答）请比较 async/await、Unity 协程、UniTask 三者的区别与适用场景。

标准答案：

协程：由 Unity 原生调度、主线程、无返回值无取消、有 GC。
async/await：C# 语言特性，原生 Task 可能在线程池执行，操作 Unity API 有生命周期与线程坑。
UniTask：struct + PlayerLoop 驱动，主线程、零分配、可取消、可组合、可绑定 Destroy，适合 Unity 异步。

9.（简答）请简述 C# 垃圾回收（GC）的基本原理，以及减少 GC 的常用方法。

标准答案：

GC 自动回收托管堆上不再被引用的对象，采用分代回收（0/1/2 代），大对象进入 LOH。
减少 GC：避免频繁 new、字符串拼接、装箱、闭包捕获、LINQ；使用对象池、缓存、结构体、StringBuilder、避免每帧分配。

10.（简答）请对比 Resources、AssetBundle、Addressables 三种资源加载方式。

标准答案：

Resources：简单但资源全部打进包体、难管理，不推荐大量使用。
AssetBundle：可分包、热更新、按需加载，但需自己管理依赖、引用计数、卸载、构建。
Addressables：在 AB 之上提供高层封装，自动处理依赖、引用计数、异步与远程更新，降低管理成本。

11.（简答）请列举 Unity 中 UI 性能优化的常见手段。

标准答案：

拆分 Canvas 减少重建范围；动静分离；使用图集减少 DrawCall；关闭不必要 Raycast Target；避免频繁布局重建（SetActive 而非改尺寸）；控制 Overdraw；长列表用虚拟列表/对象池；文字与图片合批；避免每帧改 UI 尺寸/颜色。

12.（简答）请说明 AssetBundle 的依赖管理与引用计数机制，以及常见的资源泄漏原因。

标准答案：

依赖管理：通过 Manifest 记录 AB 之间的依赖；加载资源前需先加载其依赖包；公共资源应抽到单独 AB，避免重复打包与内存翻倍。
引用计数：加载/实例化时增加引用，卸载或 Release 时减少；引用为 0 时才可安全 Unload。
常见泄漏：只加载不卸载；Unload(true) 误卸载仍被其他对象引用的资源；依赖包未正确释放。
