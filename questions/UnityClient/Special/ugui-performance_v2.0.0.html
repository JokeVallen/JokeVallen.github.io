UGUI 性能专项卷（一）

30 道客观题 + 5 道主观题，聚焦 Canvas 重建、合批、Layout、Raycast、TMP 与移动端 UI 性能。

答题记录

暂无记录，完成一次批卷后会生成。

一、客观题

1. UGUI 的 Canvas 重建主要分为哪两类？

A布局重建与图形重建
B更新与固定更新
C加载与卸载
D唤醒与销毁
查看答案与解析

正确答案：A

布局变化触发布局重建，顶点、颜色和材质变化触发图形重建。

反馈本题

2. 大量静态 UI 与频繁变化的 UI 应如何处理？

A放在同一个 Canvas
B拆到不同 Canvas
C每帧强制重建
D全部关闭合批
查看答案与解析

正确答案：B

拆分 Canvas 可以缩小重建范围，避免动态 UI 影响静态 UI。

反馈本题

3. 装饰性图片通常应如何设置？

A关闭 raycastTarget
B开启 raycastTarget
C每帧刷新材质
D强制使用 Mask
查看答案与解析

正确答案：A

只有需要响应点击的元素才开启 raycastTarget。

反馈本题

4. 矩形裁剪应优先使用哪个组件？

AMask
BRectMask2D
CCanvasGroup
DGraphicRaycaster
查看答案与解析

正确答案：B

RectMask2D 只做矩形裁剪，通常比 Mask 开销更低。

反馈本题

5. ContentSizeFitter 与 LayoutGroup 互相依赖容易导致？

A自动合批
B反复布局重建
C纹理压缩
D网络延迟
查看答案与解析

正确答案：B

父子尺寸互相依赖时容易形成布局循环和多次 Rebuild。

反馈本题

6. CanvasGroup.alpha 的主要用途是？

A统一控制组透明度
B减少 DrawCall
C裁剪矩形区域
D处理点击事件
查看答案与解析

正确答案：A

CanvasGroup.alpha 可统一控制组内 UI 透明度。

反馈本题

7. ScrollRect 大列表的推荐优化方式是？

A一次性创建全部 Item
B虚拟滚动与对象池
C每帧重建布局
D每个 Item 独立 Canvas
查看答案与解析

正确答案：B

只创建可视区附近的单元格，滚动时复用。

反馈本题

8. TMP 中文字体图集频繁扩容应如何处理？

A预生成常用字符集
B每次动态加字
C关闭字体回退
D每帧重建图集
查看答案与解析

正确答案：A

预生成常用字符集、配置 Fallback 并拆分图集可以避免频繁扩容。

反馈本题

9. 以下哪项最容易打断 UGUI 合批？

A相同图集
B相同材质
C相同 Canvas
D材质或纹理切换
查看答案与解析

正确答案：D

不同材质或纹理会导致批次切换，Mask 等状态变化也会打断合批。

反馈本题

10. Overdraw 主要消耗什么资源？

A磁盘 IO
B网络带宽
CGPU 填充率
DCPU 主线程
查看答案与解析

正确答案：C

同一像素被多次绘制会增加 GPU 填充率压力。

反馈本题

11. 将小图合并到图集的主要目的是？

A减少材质切换与合批
B自动提升分辨率
C降低音频延迟
D减少脚本编译
查看答案与解析

正确答案：A

同图集资源更容易合批，减少 DrawCall 和状态切换。

反馈本题

12. TextMeshPro 相比传统 Text 的主要优势是？

A不需要字体资源
B渲染质量与性能更好
C自动翻译文本
D只能用于 3D
查看答案与解析

正确答案：B

TMP 使用 SDF 字体，缩放清晰且通常有更好的批处理表现。

反馈本题

13. Canvas Scaler 主要用于控制什么？

A处理物理碰撞
B处理网络同步
CUI 缩放适配
D控制音频音量
查看答案与解析

正确答案：C

Canvas Scaler 处理不同分辨率下的 UI 缩放与匹配。

反馈本题

14. UGUI 点击事件最终由谁派发？

AAnimator
BEventSystem
CPhysics
DCanvasScaler
查看答案与解析

正确答案：B

EventSystem 结合 Raycaster 收集命中并派发事件。

反馈本题

15. 防止按钮连续点击的常用方式是？

A增加更多 Image
B每帧刷新布局
C关闭 EventSystem
D点击后短暂禁用
查看答案与解析

正确答案：D

点击后设置冷却时间或禁用交互，可以避免重复提交。

反馈本题

16. 以下哪种操作会触发布局重建？

A修改 RectTransform 尺寸
B修改 Text 颜色
C修改材质参数
D修改 Canvas 透明度
查看答案与解析

正确答案：A

尺寸、锚点和布局属性变化会触发布局重建；颜色变化通常触发图形重建。

反馈本题

17. 频繁 SetActive UI 对象的主要风险是？

A自动提升帧率
B触发重建与激活开销
C减少内存占用
D自动合批
查看答案与解析

正确答案：B

激活和禁用会触发 OnEnable、布局与图形重建，频繁切换应谨慎。

反馈本题

18. Canvas.ForceUpdateCanvases 的主要用途是？

A主动清理 GC
B释放全部纹理
C立即刷新 Canvas
D关闭渲染流程
查看答案与解析

正确答案：C

它会强制立即更新 Canvas，但滥用会增加 CPU 开销。

反馈本题

19. GraphicRaycaster 的主要职责是？

A合批 UI
B压缩纹理
C播放动画
D检测 UI 命中
查看答案与解析

正确答案：D

GraphicRaycaster 负责把屏幕点击转换成 UI 元素命中。

反馈本题

20. Mask 组件通常依赖什么实现裁剪？

AStencil 缓冲
B进行物理碰撞检测
C进行网络状态同步
D进行音频混音输出
查看答案与解析

正确答案：A

Mask 通过 Stencil 实现不规则裁剪，开销通常高于 RectMask2D。

反馈本题

21. RectTransform 的 Pivot 主要决定什么？

A控制文本颜色
B自身旋转缩放中心
C使用的材质球
D对象物理质量
查看答案与解析

正确答案：B

Pivot 决定自身旋转与缩放的中心点。

反馈本题

22. AspectRatioFitter 的主要用途是？

A控制音频音量
B控制物理重力
C保持 UI 宽高比
D生成字体图集
查看答案与解析

正确答案：C

AspectRatioFitter 用于在布局中维持指定宽高比。

反馈本题

23. 移动端刘海屏适配通常使用什么组件？

AMask
BCanvasGroup
CLayoutElement
DSafeArea
查看答案与解析

正确答案：D

SafeArea 会根据屏幕安全区域调整 RectTransform。

反馈本题

24. ScrollRect 的 Inertia 属性主要控制什么？

A滚动惯性
B文本颜色
C音频音量
D材质压缩
查看答案与解析

正确答案：A

Inertia 控制拖动结束后的惯性滚动效果。

反馈本题

25. TMP_Text.SetText 相比直接赋值 text 的优势是？

A自动翻译文本
B减少字符串分配
C提升网络速度
D自动生成图集
查看答案与解析

正确答案：B

SetText 支持格式化参数，减少中间字符串和 GC 分配。

反馈本题

26. CanvasRenderer 主要负责什么？

A处理物理碰撞检测
B处理网络同步过程
C提交 UI 网格渲染
D处理音频播放流程
查看答案与解析

正确答案：C

CanvasRenderer 负责把 UI 网格与材质提交给渲染流程。

反馈本题

27. Image.Type.Sliced 的主要用途是？

A自动播放动画
B压缩纹理
C处理网络消息
D九宫格拉伸
查看答案与解析

正确答案：D

Sliced 使用九宫格边框，让图片在拉伸时保持边角不变形。

反馈本题

28. LayoutElement 的主要作用是？

A覆盖布局尺寸参数
B处理点击事件
C生成字体图集
D控制音频输出
查看答案与解析

正确答案：A

LayoutElement 可以覆盖布局系统计算的最小、首选和弹性尺寸。

反馈本题

29. Canvas.sortingOrder 主要用于控制什么？

A对象物理层级
BCanvas 渲染顺序
C音频播放优先级
D控制脚本执行顺序
查看答案与解析

正确答案：B

sortingOrder 决定同一渲染模式下的 Canvas 显示顺序。

反馈本题

30. 以下哪项通常不会减少 UGUI DrawCall？

A合并图集
B复用相同材质
C减少 Mask 切换
D增加更多 Mask
查看答案与解析

正确答案：D

增加 Mask 会增加状态切换和额外绘制，通常不利于合批。
