C# / GC / 异步专项卷（一）

30 道客观题 + 5 道主观题，聚焦 C# 运行时、GC 与 Unity 异步。

答题记录

暂无记录，完成一次批卷后会生成。

一、客观题

1. 关于 GC.Collect，正确的说法是？

A应每帧主动调用
B只回收非托管内存
C可能造成明显卡顿
D会立即释放引用对象
查看答案与解析

正确答案：C

强制完整回收可能造成明显卡顿，且不会释放仍有引用的对象。

反馈本题

2. using 语句最终会编译成什么结构？

Atry/finally
Block 语句
Cswitch 分支
Dforeach 循环
查看答案与解析

正确答案：A

using 会确保离开作用域时调用 Dispose，即使发生异常也会执行。

反馈本题

3. 实现 IDisposable 的常见目的是？

A提升序列化速度
B自动创建线程
C直接替代 GC
D及时释放资源
查看答案与解析

正确答案：D

Dispose 由调用方主动释放托管与非托管资源，finalizer 只作兜底。

反馈本题

4. StringBuilder 的主要优势是？

A字符串不可变安全
B减少临时字符串
C自动保证线程安全
D比 string 更省内存
查看答案与解析

正确答案：B

频繁拼接时 StringBuilder 避免每次生成新 string，降低 GC 压力。

反馈本题

5. Span<T> 的主要限制是？

A可以随意进行装箱
B可以作为类字段保存
C不能跨 await 保存
D只能存储引用类型
查看答案与解析

正确答案：C

Span 是 ref struct，不能装箱、不能作为类字段、不能跨 await 保留。

反馈本题

6. 关于 ValueTask，正确的说法是？

A可以任意多次 await
B一般只消费一次
C一定比 Task 慢
D不能返回结果
查看答案与解析

正确答案：B

ValueTask 为减少分配设计，重复消费可能触发未定义行为。

反馈本题

7. 关于 async void，以下说法不正确的是？

A可用于 UI 事件回调
B异常较难被捕获
C总是优于 async Task
D没有可等待的 Task
查看答案与解析

正确答案：C

async void 没有可等待 Task，异常会抛到同步上下文，通常不应优于 async Task。

反馈本题

8. Unity 中使用 ConfigureAwait(false) 的风险是？

A一定编译失败
B可能离开主线程
C自动提升帧率
D只能用于 Delay
查看答案与解析

正确答案：B

ConfigureAwait(false) 允许延续在线程池执行，之后访问 Unity API 可能异常。

反馈本题

9. WeakReference<T> 的主要作用是？

A不阻止对象回收
B提供强引用
C线程安全集合
D只能存值类型
查看答案与解析

正确答案：A

弱引用适合缓存与监听器表，使用前需检查目标是否存活。

反馈本题

10. Interlocked 提供的是什么操作？

A原子操作接口
B线程同步锁
C对象序列化过程
D反射调用接口
查看答案与解析

正确答案：A

Interlocked 用于原子自增、交换等无锁操作。

反馈本题

11. 在 Task.Run 中访问 transform.position 会怎样？

A完全支持
B通常不允许
C自动切回主线程
D只在 Editor 报错
查看答案与解析

正确答案：B

Unity 大部分 API 不是线程安全的，需要切回主线程更新场景对象。

反馈本题

12. UniTask 相比原生 Task 的优势是？

A只能用于协程调用场景
B完全不需要任何取消
C支持多线程渲染管线
D接入 PlayerLoop
查看答案与解析

正确答案：D

UniTask 针对 Unity 优化，支持 PlayerLoop、低分配、取消和组合操作。

反馈本题

13. CancellationTokenSource 取消后还应做什么？

A调用 Dispose
B立即重启线程
C调用 GC.Collect
D清空静态字段
查看答案与解析

正确答案：A

Cancel 后应 Dispose，避免注册回调与内部资源残留。

反馈本题

14. Lazy<T> 的线程安全行为由什么决定？

A创建字段的数量
B类型的名称长度
C线程安全模式
DGC 的代数编号
查看答案与解析

正确答案：C

LazyThreadSafetyMode 决定是否加锁、是否允许重复初始化。

反馈本题

15. IEnumerable<T> 的主要特点是？

A立即执行查询
B通常延迟执行
C只能遍历一次
D一定分配数组
查看答案与解析

正确答案：B

LINQ 与迭代器通常延迟执行，只有枚举时才真正计算。

反馈本题

16. 对 List<T> 使用 foreach 时，通常使用什么避免装箱？

A每次创建新数组
B通过反射调用
C生成动态代理
Dstruct 枚举器
查看答案与解析

正确答案：D

List<T>.Enumerator 是 struct，直接使用可避免接口装箱。

反馈本题

17. 什么情况下 struct 会发生装箱？

A转为 object
B作为方法参数传递
C放入普通数组中
D作为类字段保存
查看答案与解析

正确答案：A

struct 转为引用类型或接口时需要在堆上创建对象。

反馈本题

18. 修改 Dictionary 中作为 key 的可变字段后，最可能？

A自动重新哈希
B找不到原来的项
CDictionary 自动排序
D立即抛出异常
查看答案与解析

正确答案：B

key 的哈希变化后会定位到错误的桶，导致查找失败。

反馈本题

19. ArrayPool<T> 的正确使用方式是？

A租用后不归还
B每次新建一个池
C租用后归还并清理
D只能用于值类型
查看答案与解析

正确答案：C

ArrayPool 复用数组减少 GC，但必须归还，敏感数据还应清理。

反馈本题

20. 关于 finalizer，正确的说法是？

A一定会立即执行
B一定先于 Dispose
C可以访问 Unity 对象
D执行时机不确定
查看答案与解析

正确答案：D

finalizer 由 GC 调度，时机不可控，且不应访问已销毁的 Unity 对象。

反馈本题

21. stackalloc 的主要特点是？

A在栈上分配
B在托管堆分配
C可以跨方法保存
D只能用于类
查看答案与解析

正确答案：A

stackalloc 分配在栈上，适合小缓冲区，不能跨方法返回。

反馈本题

22. C# record 的默认相等语义是？

A引用地址相等
B基于值相等
C永远不相等
D基于哈希地址
查看答案与解析

正确答案：B

record 默认按成员值比较，适合数据传输对象与不可变模型。

反馈本题

23. 关于 LINQ，以下说法不正确的是？

A一定比 for 更快
B通常延迟执行
C可能产生分配
D可用于集合查询
查看答案与解析

正确答案：A

LINQ 链式调用可能产生迭代器、委托与闭包分配，并不一定更快。

反馈本题

24. string.Intern 的主要作用是？

A压缩字符串内容
B执行深拷贝
C保证线程安全拼接
D放入字符串驻留池
查看答案与解析

正确答案：D

驻留池适合少量高频固定字符串，滥用会增加驻留池压力。

反馈本题

25. 在 Unity 中使用线程池要注意什么？

A回调需切回主线程
B可以直接操作 UI
C不再需要同步
D线程池会自动销毁对象
查看答案与解析

正确答案：A

后台线程不能直接访问 Unity API，结果需要切回主线程应用。

反馈本题

26. async 方法通常会生成什么？

A不会产生任何分配
B可能生成状态机
C一定导致编译失败
D只能用于 Editor
查看答案与解析

正确答案：B

async 状态机可能产生分配，高频异步应关注 GC。

反馈本题

27. 多个取消源需要联合取消时使用？

ACancellationToken.None
B新建 Thread
CCreateLinkedTokenSource
DGC.Collect
查看答案与解析

正确答案：C

链接令牌可以同时响应多个取消源，并需要 Dispose。

反馈本题

28. SafeHandle 的主要用途是？

A自动创建线程
B替代 string
C序列化对象
D封装非托管句柄
查看答案与解析

正确答案：D

SafeHandle 提供可靠的非托管资源释放，避免句柄泄漏。

反馈本题

29. .NET GC 的代数通常是？

A0/1/2 三代
B只有一代
C一共五代
D由 CPU 决定
查看答案与解析

正确答案：A

新对象进入 0 代，存活越久越可能晋升到 1、2 代。

反馈本题

30. Unity 对象被 Destroy 后，obj == null 通常是？

A一定为 false
B通常为 true
C一定抛异常
D随机结果
查看答案与解析

正确答案：B

Unity 重载了相等运算符，已销毁对象与 null 比较通常返回 true。
