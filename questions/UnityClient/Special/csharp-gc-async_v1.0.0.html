题卷版本：v1.0.0

本卷共 30 道客观题 + 5 道主观题，聚焦 C# 运行时、GC 与 Unity 异步。

一、客观题

1. 关于 GC.Collect，正确的说法是？
A. 应每帧调用　B. 只回收非托管内存　C. 强制回收可能造成卡顿，不应滥用　D. 会立即释放所有引用对象

  • 正确答案：C
  • 解析：强制完整回收可能造成明显卡顿，且不会释放仍有引用的对象。

2. using 语句最终会编译成什么结构？
A. try/finally，在 finally 中调用 Dispose　B. 普通方法调用　C. lock 语句　D. 反射调用

  • 正确答案：A
  • 解析：using 确保离开作用域时调用 Dispose，即使发生异常也会执行。

3. 实现 IDisposable 的常见目的是？
A. 提升序列化速度　B. 自动创建线程　C. 替代 GC　D. 及时释放资源，finalizer 只作兜底

  • 正确答案：D
  • 解析：Dispose 由调用方主动释放托管与非托管资源，finalizer 执行时机不确定。

4. StringBuilder 的主要优势是？
A. 字符串不可变更安全　B. 可变缓冲区，减少频繁拼接的临时对象　C. 自动线程安全　D. 比 string 更省内存

  • 正确答案：B
  • 解析：频繁拼接时 StringBuilder 避免每次生成新 string，降低 GC 压力。

5. Span<T> 的限制是？
A. 是 ref struct，不能装箱或作为类字段　B. 只能用于字符串　C. 可以跨 await　D. 只能存引用类型

  • 正确答案：A
  • 解析：Span 只能存在于栈上，不能装箱、不能作为类字段、不能跨 await。

6. 关于 ValueTask，正确的是？
A. 可以任意多次 await　B. 一定比 Task 慢　C. 通常只消费一次　D. 不能返回值

  • 正确答案：C
  • 解析：ValueTask 为减少分配设计，重复消费可能触发未定义行为。

7. async void 的主要风险是？
A. 一定编译失败　B. 不能使用 await　C. 只能用于 UI　D. 异常无法被调用方捕获

  • 正确答案：D
  • 解析：异常会直接抛到同步上下文，调用方无法 try/catch；应优先用 Task 或 UniTaskVoid。

8. 在 Unity 主线程使用 ConfigureAwait(false) 的风险是？
A. 编译失败　B. 后续代码可能不在主线程，访问 Unity API 不安全　C. 自动提升性能　D. 只能用于 Task.Delay

  • 正确答案：B
  • 解析：ConfigureAwait(false) 允许延续在线程池执行，之后访问 Transform 等 API 可能异常。

9. WeakReference<T> 的作用是？
A. 不阻止 GC 回收目标对象　B. 提供强引用　C. 线程安全集合　D. 只能存值类型

  • 正确答案：A
  • 解析：弱引用适合缓存与监听器表，使用前需检查目标是否存活。

10. Interlocked 提供的是？
A. 线程锁　B. 序列化　C. 原子操作　D. 反射

  • 正确答案：C
  • 解析：Interlocked 用于原子自增、交换等无锁操作。

11. 在 Task.Run 中访问 transform.position 会怎样？
A. 完全支持　B. 不允许，Unity API 通常只能在主线程访问　C. Unity 自动切回主线程　D. 只在 Editor 报错

  • 正确答案：B
  • 解析：Unity 大部分 API 不是线程安全的，需要切回主线程更新场景对象。

12. UniTask 相比原生 Task 的优势是？
A. 只能用于协程　B. 不需要取消　C. 支持多线程渲染　D. 与 PlayerLoop 集成且分配更低

  • 正确答案：D
  • 解析：UniTask 针对 Unity 优化，支持 PlayerLoop、低分配、取消和组合操作。

13. 取消 CancellationTokenSource 后还应做什么？
A. Dispose 释放资源　B. 立即重启线程　C. 调用 GC.Collect　D. 清空所有静态字段

  • 正确答案：A
  • 解析：Cancel 后应 Dispose，避免注册回调与内部资源残留。

14. Lazy<T> 的线程安全行为由什么决定？
A. 字段数量　B. 类名　C. LazyThreadSafetyMode　D. GC 代数

  • 正确答案：C
  • 解析：LazyThreadSafetyMode 决定是否加锁、是否允许重复初始化。

15. IEnumerable<T> 的特点是？
A. 立即执行　B. 通常延迟执行　C. 只能遍历一次　D. 一定分配数组

  • 正确答案：B
  • 解析：LINQ 与迭代器通常延迟执行，只有在枚举时才真正计算。

16. 对 List<T> 使用 foreach 时，编译器通常使用什么避免装箱？
A. 每次创建数组　B. 反射　C. 动态代理　D. struct 枚举器

  • 正确答案：D
  • 解析：List<T>.Enumerator 是 struct，直接使用可避免接口装箱；转成 IEnumerable<T> 可能装箱。

17. 什么情况下 struct 会发生装箱？
A. 赋值给 object 或接口　B. 作为方法参数传递　C. 放在数组里　D. 作为字段

  • 正确答案：A
  • 解析：struct 转为引用类型或接口时需要在堆上创建对象。

18. 修改 Dictionary 中作为 key 的可变对象字段后，最可能？
A. 自动重新哈希　B. 找不到原项　C. Dictionary 自动排序　D. 立即抛异常

  • 正确答案：B
  • 解析：key 的哈希变化后定位到错误桶，导致找不到原项。

19. ArrayPool<T> 的正确使用方式是？
A. 不归还数组　B. 每次新建池　C. 租用后必须归还，并注意清零　D. 只能用于值类型

  • 正确答案：C
  • 解析：ArrayPool 复用数组减少 GC，但必须归还，敏感数据还应清理。

20. 关于 finalizer，正确的是？
A. 会立即执行　B. 一定先于 Dispose　C. 可以访问 Unity 对象　D. 执行时机不确定，不能依赖它清理

  • 正确答案：D
  • 解析：finalizer 由 GC 调度，时机不可控，且不应访问已销毁的 Unity 对象。

21. stackalloc 的特点是？
A. 在栈上分配，大小受限且生命周期有限　B. 在托管堆分配　C. 自动跨方法保存　D. 只能用于类

  • 正确答案：A
  • 解析：stackalloc 分配在栈上，适合小缓冲区，不能跨方法返回。

22. C# record 的默认相等语义是？
A. 引用相等　B. 基于值的相等　C. 永远不相等　D. 基于哈希地址

  • 正确答案：B
  • 解析：record 默认按成员值比较，适合数据传输对象与不可变模型。

23. LINQ 的主要性能注意点是？
A. 一定比 for 快　B. 不会分配　C. 通常延迟执行且可能产生分配　D. 只能用于数组

  • 正确答案：C
  • 解析：LINQ 链式调用可能产生迭代器、委托与闭包分配，热点路径应谨慎。

24. string.Intern 的作用是？
A. 压缩字符串　B. 深拷贝　C. 线程安全拼接　D. 放入字符串驻留池

  • 正确答案：D
  • 解析：驻留池适合少量高频固定字符串，滥用会增加驻留池压力。

25. 在 Unity 中使用线程池时要注意？
A. 不能阻塞主线程，回调需切回主线程访问 Unity API　B. 可以直接操作 UI　C. 不需要同步　D. 线程池会自动销毁对象

  • 正确答案：A
  • 解析：后台线程不能直接访问 Unity API，结果需要切回主线程应用。

26. async 方法通常会生成什么？
A. 不会分配　B. 可能生成状态机对象，热点异步要注意分配　C. 一定编译失败　D. 只能在 Editor 使用

  • 正确答案：B
  • 解析：async 状态机可能装箱/分配，UniTask 等方案可降低高频异步的 GC。

27. 多个取消源需要联合取消时使用？
A. CancellationToken.None　B. 新建 Thread　C. CreateLinkedTokenSource　D. GC.Collect

  • 正确答案：C
  • 解析：链接令牌可以同时响应多个取消源，并需要 Dispose。

28. SafeHandle 的主要用途是？
A. 自动创建线程　B. 替代 string　C. 序列化对象　D. 封装非托管句柄并配合 Dispose 释放

  • 正确答案：D
  • 解析：SafeHandle 提供可靠的非托管资源释放，避免句柄泄漏。

29. .NET GC 的代数通常是？
A. 0/1/2 三代，新对象在 0 代　B. 只有一代　C. 五代　D. 由 CPU 决定

  • 正确答案：A
  • 解析：新对象进入 0 代，存活越久越可能晋升到 1、2 代。

30. Unity 中 UnityEngine.Object 被 Destroy 后，引用比较 obj == null 的结果是？
A. 一定为 false　B. 通常为 true，因为重载了相等运算符　C. 一定抛异常　D. 随机

  • 正确答案：B
  • 解析：Unity 重载了 ==，已销毁对象与 null 比较会返回 true，但底层托管引用仍可能存在。

二、主观题

1. 如何减少热点路径的 GC？

  • 参考点：Profiler GC Alloc、缓存组件/字符串、避免 LINQ/闭包/装箱、NonAlloc、对象池、StringBuilder、TMP SetText。

2. 如何设计一个低分配的 Update 系统？

  • 参考点：集中更新、避免每帧查找组件、缓存引用、结构体/数组、事件驱动、分帧、对象池。

3. async/await 在 Unity 中如何安全使用？

  • 参考点：CancellationToken、UniTask、主线程切回、异常处理、对象销毁检查、避免 async void。

4. 如何排查一次 GC 尖峰？

  • 参考点：Profiler Timeline、GC Alloc 排序、定位调用栈、区分 string/LINQ/闭包/协程、优化后对比。

5. 如何设计一个可复用的异步请求层？

  • 参考点：取消、超时、重试、幂等、异常分类、主线程回调、生命周期绑定、日志。
