30 道高频快问快答，适合面试前 15 分钟热身。

一、快问快答

1. 关于 string，正确的说法是？

A可变引用类型
B不可变引用类型
C固定长度值类型
D只能存储 ASCII
查看答案与解析

正确答案：B

string 不可变，每次修改都会产生新的字符串对象。

反馈本题

2. 接口与抽象类的主要区别是？

A接口可以实例化
B抽象类可以多继承
C一个类可实现多个接口
D接口不能有方法
查看答案与解析

正确答案：C

C# 单继承类，多实现接口。

反馈本题

3. 关于 GC.Collect，正确的说法是？

A应每帧主动调用
B只回收非托管内存
C会立即释放所有对象
D强制回收可能造成卡顿
查看答案与解析

正确答案：D

强制完整回收可能造成明显卡顿，且不会释放仍有引用的对象。

反馈本题

4. async void 的主要风险是？

A异常无法被调用方捕获
B一定编译失败
C不能使用 await
D只能用于 UI
查看答案与解析

正确答案：A

异常会直接抛到同步上下文，调用方无法 try/catch。

反馈本题

5. Awake 与 Start 的执行时机是？

AStart 先于 Awake
BAwake 先于 Start
C两者完全同时执行
D执行顺序完全随机
查看答案与解析

正确答案：B

Awake 用于初始化自身引用，Start 在第一帧 Update 前执行。

反馈本题

6. 物理计算应优先放在哪个回调？

AUpdate
BLateUpdate
CFixedUpdate
DOnGUI
查看答案与解析

正确答案：C

FixedUpdate 按固定时间步长调用，适合物理计算。

反馈本题

7. 对象销毁后，协程通常会怎样？

A继续正常执行
B自动转为线程
C自动保存状态
D无法正常执行
查看答案与解析

正确答案：D

协程宿主销毁后无法正常执行，清理逻辑应直接执行。

反馈本题

8. 大量静态 UI 与频繁变化的动态 UI 应？

A拆到不同 Canvas
B放在同一个 Canvas
C增加更多 Mask
D每帧强制重建
查看答案与解析

正确答案：A

拆分 Canvas 可缩小批次重建范围。

反馈本题

9. 装饰性图片和文本通常应该？

A全部开启 raycastTarget
B关闭 raycastTarget
C每帧刷新材质
D强制使用 Mask
查看答案与解析

正确答案：B

只有需要响应点击的元素才开启 raycastTarget。

反馈本题

10. 滚动列表矩形裁剪应优先使用？

AMask
BCanvasGroup
CRectMask2D
DGraphicRaycaster
查看答案与解析

正确答案：C

RectMask2D 只做矩形裁剪，通常比 Mask 更轻。

反馈本题

11. 大列表使用 ScrollRect 时推荐？

A一次性实例化全部 Item
B每帧重建布局
C每个 Item 独立 Canvas
D虚拟滚动加对象池
查看答案与解析

正确答案：D

只创建可视区附近的单元格，滚动时复用。

反馈本题

12. Addressables 释放资源应使用？

AAddressables.Release(handle)
BDestroy(handle)
CGC.Collect()
D只调用 UnloadUnusedAssets
查看答案与解析

正确答案：A

Release 减少引用计数，计数归零后才可能卸载。

反馈本题

13. AssetBundle 调用 Unload(true) 的风险是？

A一定安全无风险
B可能卸载正在使用的资源
C只卸载依赖包
D完全不释放内存
查看答案与解析

正确答案：B

会销毁已加载 Asset，场景中仍在使用的资源会变成 Missing。

反馈本题

14. 大量使用 Resources.Load 的主要问题是？

A加载太快
B自动热更
C无法热更且资源常驻包体
D不能加载 Prefab
查看答案与解析

正确答案：C

Resources 资源全部打进安装包，无法热更，且引用不透明。

反馈本题

15. Profiler 中定位 GC 分配应重点看？

A当前屏幕分辨率
B实时网络延迟
C显卡型号参数
DGC 分配列
查看答案与解析

正确答案：D

GC Alloc 能定位热点路径上的托管堆分配。

反馈本题

16. List<T> 扩容时通常如何处理？

A按近似翻倍扩容并复制
B容量保持不变
C每次只增加一个
D自动按值排序
查看答案与解析

正确答案：A

List 容量不足时会分配更大的数组并复制元素。

反馈本题

17. Dictionary 平均查找复杂度是？

AO(n)
BO(1)
CO(log n)
DO(n log n)
查看答案与解析

正确答案：B

哈希表平均 O(1)，最坏情况可能退化。

反馈本题

18. struct 的默认值特点是？

A所有字段为 null
B自动调用有参构造
C字段为各自类型的零值
D不能作为字段
查看答案与解析

正确答案：C

struct 默认值会把字段初始化为零值。

反馈本题

19. lock 语句底层主要基于？

AMutex
BSemaphore
CThreadPool
DMonitor
查看答案与解析

正确答案：D

C# lock 编译为 Monitor.Enter/Exit。

反馈本题

20. 两个 string 使用 == 比较时？

A比较字符串内容
B比较引用地址
C总是返回 false
D一定编译失败
查看答案与解析

正确答案：A

string 重载了 ==，比较的是字符串内容。

反馈本题

21. 相机跟随通常放在哪个回调？

AUpdate
BLateUpdate
CFixedUpdate
DOnGUI
查看答案与解析

正确答案：B

LateUpdate 在 Update 后执行，适合相机跟随。

反馈本题

22. OnEnable 的调用时机是？

A只在第一次激活时
B只在销毁时
C每次启用时
D每帧固定调用
查看答案与解析

正确答案：C

OnEnable 在对象或组件每次被启用时调用。

反馈本题

23. DontDestroyOnLoad 的作用是？

A自动销毁对象
B只保留一帧
C只对 UI 有效
D切场景时保留对象
查看答案与解析

正确答案：D

对象在场景切换时不会被销毁。

反馈本题

24. 停止指定协程应使用？

AStopCoroutine
BDestroy
CStopAllCoroutines 一定
D外部调用 yield break
查看答案与解析

正确答案：A

StopCoroutine 可停止指定协程；StopAllCoroutines 会停止全部。

反馈本题

25. Physics.OverlapSphereNonAlloc 的优势是？

A一定更快
B复用数组减少 GC
C只能用于 2D
D不会返回结果
查看答案与解析

正确答案：B

NonAlloc 版本由调用方传入数组，避免每次分配。

反馈本题

26. ContentSizeFitter 与 LayoutGroup 互相依赖容易导致？

A自动合批
B纹理压缩
C反复布局重建
D网络延迟
查看答案与解析

正确答案：C

父子尺寸互相依赖时容易形成布局循环和多次 Rebuild。

反馈本题

27. CanvasGroup.alpha 的主要用途是？

A减少 DrawCall
B裁剪矩形
C处理点击
D统一控制透明度
查看答案与解析

正确答案：D

CanvasGroup.alpha 可统一控制组内 UI 透明度。

反馈本题

28. 以下哪项不是减少 GC 的常见做法？

A在 Update 中拼接字符串
B缓存组件引用
C使用对象池
D使用 NonAlloc API
查看答案与解析

正确答案：A

字符串拼接会产生新的字符串对象，增加托管堆分配。

反馈本题

29. 以下哪项不属于 Unity 生命周期方法？

AAwake 初始化方法
BStart 启动方法
CUpdate 更新方法
DConstructor 构造方法
查看答案与解析

正确答案：D

构造函数不属于 Unity 生命周期回调。

反馈本题

30. 以下哪项不是合理的资源分包原则？

A按模块划分
B按更新频率划分
C每个文件单独一个包
D兼顾加载与依赖
查看答案与解析

正确答案：C

每个文件单独打包会带来大量包和依赖管理成本。
