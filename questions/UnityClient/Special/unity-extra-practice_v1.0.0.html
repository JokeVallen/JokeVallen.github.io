一、客观题

1. Physics.Raycast 的 layerMask 参数应传入什么？

ALayer 名称字符串
B1 << Layer 位掩码
CCollider 实例 ID
D场景对象引用
查看答案与解析

正确答案：B

物理查询使用位掩码，常用 1 << LayerMask.NameToLayer("Enemy")。

反馈本题

2. Time.deltaTime 最适合用于哪类逻辑？

A固定物理步长计算
B逐帧移动与插值
C编辑器资源导入
D场景加载进度
查看答案与解析

正确答案：B

deltaTime 表示上一帧耗时，用于逐帧逻辑可以保持大致帧率无关。

反馈本题

3. 刚体的物理移动通常应放在哪个生命周期？

AUpdate
BLateUpdate
CFixedUpdate
DOnGUI
查看答案与解析

正确答案：C

物理更新在固定时间步中执行，Rigidbody 移动应在 FixedUpdate。

反馈本题

4. OnTriggerEnter 触发通常要求至少一方具备什么？

A必须是 UI 元素
B双方都开启 Kinematic
C必须使用 MeshCollider
D一方带刚体与触发器
查看答案与解析

正确答案：D

触发检测需要 Collider.isTrigger，且运动体通常需要 Rigidbody。

反馈本题

5. 让 NavMeshAgent 在到达目标后停止，最直接的方式是？

A设置 isStopped 为 true
B销毁 Agent 组件
C禁用整个场景对象
D修改 Time.timeScale
查看答案与解析

正确答案：A

isStopped 可以暂停 Agent 移动，恢复时再设为 false。

反馈本题

6. yield return new WaitForSeconds(1f) 受什么影响？

A受时间缩放影响
B只受真实时间影响
C不受任何时间影响
D只受帧率影响
查看答案与解析

正确答案：A

WaitForSeconds 使用缩放时间；需要真实时间可用 WaitForSecondsRealtime。

反馈本题

7. ScriptableObject 在编辑器热重载后可能丢失什么？

A资源文件本身
B全部 public 字段
C未序列化运行时字段
D资源文件名称
查看答案与解析

正确答案：C

只有可序列化字段会保留，运行时临时状态需要额外重建。

反馈本题

8. 让 private 字段出现在 Inspector 中应使用？

Astatic 修饰符
Breadonly 修饰符
CSerializeField
DNonSerialized
查看答案与解析

正确答案：C

SerializeField 可序列化私有字段并显示在 Inspector。

反馈本题

9. AssetDatabase 相关 API 可以在哪里使用？

A仅编辑器代码
B仅 Android 平台
C仅 iOS 平台
D所有运行时平台
查看答案与解析

正确答案：A

AssetDatabase 属于 UnityEditor，打包后不可用。

反馈本题

10. RectTransform.anchoredPosition 表示什么？

A世界坐标位置
B相对锚点的位置
CCanvas 缩放比例
D屏幕像素坐标
查看答案与解析

正确答案：B

anchoredPosition 是相对锚点参考系的二维位置。

反馈本题

11. 频繁调用 ForceRebuildLayoutImmediate 的主要风险是？

A自动减少 DrawCall
B造成同步布局重建和卡顿
C提升图集合批效率
D降低运行时内存
查看答案与解析

正确答案：B

强制立即重建会打断批处理并产生较高 CPU 开销。

反馈本题

12. TextMeshPro 使用 SDF 字体的主要优势是？

A完全不需要字体图集
B只支持英文文本
C缩放清晰且支持描边
D自动翻译全部文本
查看答案与解析

正确答案：C

SDF 字体在不同字号下更清晰，也便于描边和阴影。

反馈本题

13. Animator 参数使用字符串哈希的主要目的是？

A减少字符串比较开销
B自动生成动画剪辑
C压缩动画文件大小
D改变状态机结构
查看答案与解析

正确答案：A

Animator.StringToHash 可避免每帧字符串查找。

反馈本题

14. StateMachineBehaviour 适合处理什么？

A仅 UI 布局
B网络同步
C资源打包
D动画状态回调
查看答案与解析

正确答案：D

StateMachineBehaviour 可挂到 Animator 状态上处理状态事件。

反馈本题

15. 播放一次性短音效应优先使用？

AAudioSource.PlayOneShot
B每帧新建 AudioSource
C每帧 Resources.Load
D停止所有 AudioSource
查看答案与解析

正确答案：A

PlayOneShot 可在现有 AudioSource 上叠加播放短音效。

反馈本题

16. 修改 ParticleSystem 的持续发射速率应访问？

Amain 模块
Bemission 模块
Cshape 模块
Drenderer 模块
查看答案与解析

正确答案：B

emission.rateOverTime 控制持续发射速率。

反馈本题

17. QualitySettings.vSyncCount 设为 0 通常表示？

A强制固定 30 帧
B完全关闭渲染
C关闭垂直同步
D开启双缓冲
查看答案与解析

正确答案：C

vSyncCount 为 0 时关闭垂直同步，帧率上限交给 targetFrameRate。

反馈本题

18. 设置 Application.targetFrameRate 时，移动端通常还需要考虑？

A屏幕刷新率与平台限制
B只考虑编辑器设置
C只考虑音频采样率
D不需要任何验证
查看答案与解析

正确答案：A

高刷屏与平台策略会影响实际帧率，需要真机验证。

反馈本题

19. UnityWebRequest 使用后必须做什么？

A直接丢弃引用
B转换为 Texture2D
C停止整个场景
D调用 Dispose 释放资源
查看答案与解析

正确答案：D

UnityWebRequest 持有非托管资源，应使用 using 或 Dispose。

反馈本题

20. JsonUtility 的一个常见限制是？

A完全不支持数组
B只能读取二进制
C不支持字典与多态
D只能用于编辑器
查看答案与解析

正确答案：C

JsonUtility 对字典、接口和多态支持有限，复杂数据需自定义序列化。

反馈本题

21. PlayerPrefs 最适合存储什么？

A大量二进制资源
B少量简单用户配置
C完整存档数据库
D运行时纹理对象
查看答案与解析

正确答案：B

PlayerPrefs 适合少量配置，不适合大量结构化存档。

反馈本题

22. DontDestroyOnLoad 使用不当时最常见的问题是？

A产生重复管理器对象
B自动删除当前场景
C无法加载任何资源
D禁用全部物理
查看答案与解析

正确答案：A

多次进入场景可能重复创建常驻对象，需要单例或重复检测。

反馈本题

23. SceneManager.sceneLoaded 回调适合做什么？

A场景加载完成后初始化引用
B在加载前销毁全部资源
C替代每帧 Update
D编译 C# 脚本
查看答案与解析

正确答案：A

sceneLoaded 在场景加载完成后触发，适合做依赖查找和初始化。

反馈本题

24. async void 方法的主要风险是？

A完全无法编译
B异常无法被调用方捕获
C一定会阻塞主线程
D不能使用 await
查看答案与解析

正确答案：B

async void 的异常通常直接抛到同步上下文，难以统一捕获。

反馈本题

25. 在 Unity 中把 Task 结果切回主线程，常用什么？

A默认 ContinueWith
BThread.Sleep
C主线程同步上下文
DGC.Collect
查看答案与解析

正确答案：C

Unity 主线程上下文需要显式切回，UniTask 等库提供了更直接的切换。

反馈本题

26. Unity Job System 中 Job 通常应使用什么类型？

Aclass
Bstruct
CScriptableObject
DMonoBehaviour
查看答案与解析

正确答案：B

Job 通常为 struct，以满足 Burst 和内存安全要求。

反馈本题

27. Burst 编译器不能直接处理以下哪类代码？

A基本数学运算
BNativeArray 遍历
C固定大小循环
D托管对象分配
查看答案与解析

正确答案：D

Burst 面向高性能原生代码，托管分配和复杂引用类型受限。

反馈本题

28. NativeArray 使用后通常应调用？

ADestroy
BDispose
CGC.Collect
DUnloadUnusedAssets
查看答案与解析

正确答案：B

NativeArray 持有原生内存，需要 Dispose 释放。

反馈本题

29. 以下哪项不是减少 UI DrawCall 的常见方式？

A合并图集
B减少 Mask 切换
C增加透明叠层
D复用相同材质
查看答案与解析

正确答案：C

增加透明叠层会增加 Overdraw 和状态切换，通常不利于性能。

反馈本题

30. 以下哪项不是排查帧率问题的合理第一步？

A用 Profiler 看耗时
B用 Frame Debugger 看绘制
C直接猜测并重写逻辑
D在真机上复现问题
查看答案与解析

正确答案：C

应先测量定位瓶颈，再针对性修改，避免盲目重写。
