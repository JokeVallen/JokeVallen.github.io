题卷版本：v1.0.0

本卷共 30 道客观题 + 5 道主观题，聚焦渲染管线、URP、合批与 GPU 性能。

一、客观题

1. URP 中启用 SRP Batcher 的关键要求是？
A. 必须是 UI 对象　B. Shader 兼容 SRP Batcher 且使用相同 CBUFFER 布局　C. 必须开启 GPU Instancing　D. 必须是静态物体

  • 正确答案：B
  • 解析：SRP Batcher 依赖 Shader 的 CBUFFER 一致性来减少材质属性设置开销，不兼容的 Shader 无法参与。

2. 查看每个 DrawCall 的渲染状态应使用？
A. Memory Profiler　B. CPU Profiler　C. Network Profiler　D. Frame Debugger

  • 正确答案：D
  • 解析：Frame Debugger 按渲染顺序展示 DrawCall、Shader、材质和批处理信息。

3. GPU Instancing 适合什么场景？
A. 大量相同 Mesh/Material 的物体　B. 所有 UI 元素　C. 不同 Shader 的物体　D. 只有透明物体

  • 正确答案：A
  • 解析：Instancing 通过每实例数据批量绘制相同网格与材质，减少 DrawCall。

4. MaterialPropertyBlock 常用于？
A. 压缩纹理　B. 生成图集　C. 每实例覆盖材质属性而不复制材质　D. 网络同步

  • 正确答案：C
  • 解析：它可给单个 Renderer 设置属性，避免创建材质副本，但可能影响 SRP Batcher。

5. Overdraw 主要消耗什么资源？
A. 磁盘 IO　B. 网络带宽　C. CPU 主线程　D. GPU 填充率

  • 正确答案：D
  • 解析：同一像素被多次绘制会增加 GPU 填充率压力，透明 UI 与粒子最常见。

6. Shader Variants 过多会？
A. 增加构建时间、包体和加载开销　B. 减少包体　C. 提升帧率　D. 没有影响

  • 正确答案：A
  • 解析：变体膨胀会增加构建和加载成本，应通过关键字裁剪与 Stripping 控制。

7. 透明物体通常如何排序？
A. 从近到远　B. 通常从远到近　C. 随机　D. 与相机无关

  • 正确答案：B
  • 解析：透明物体按距离从远到近绘制，排序错误会出现穿插。

8. 静态合批的要求是？
A. 任意移动物体　B. 只对 UI 有效　C. 物体静态且共享材质等条件　D. 不需要相同材质

  • 正确答案：C
  • 解析：静态合批把静态网格合并成大网格，受材质、顶点数和平台限制。

9. 实时阴影的主要开销来源是？
A. 额外 Shadow Pass 与阴影贴图　B. 音频解码　C. 网络同步　D. GC

  • 正确答案：A
  • 解析：阴影需要从光源视角渲染深度，并增加采样与贴图开销。

10. 后处理效果的主要代价是？
A. 减少 DrawCall　B. 降低内存　C. 提升 CPU　D. 额外的全屏 Pass 与带宽

  • 正确答案：D
  • 解析：Bloom、模糊、色彩校正等通常需要额外全屏渲染与纹理采样。

11. Mipmap 主要解决什么问题？
A. 音频延迟　B. 远处纹理采样闪烁与带宽　C. 网络抖动　D. UI 布局

  • 正确答案：B
  • 解析：Mipmap 根据距离选择低分辨率层级，减少锯齿与纹理带宽。

12. ASTC 主要用于？
A. 音频压缩　B. 网络协议　C. 移动端纹理压缩　D. UI 布局

  • 正确答案：C
  • 解析：ASTC 在移动端按块大小平衡质量与体积。

13. 线性色彩空间的主要影响是？
A. 光照计算更符合物理，纹理需正确标记 sRGB　B. 自动减少 DrawCall　C. 只能用于 UI　D. 不需要 Gamma

  • 正确答案：A
  • 解析：线性空间下光照混合更正确，但需要正确设置纹理 sRGB 与颜色空间。

14. Lightmap 的主要用途是？
A. 实时阴影　B. 音频　C. 网络　D. 烘焙静态光照，降低实时计算

  • 正确答案：D
  • 解析：Lightmap 把静态光照烘焙到纹理，减少实时灯光与阴影开销。

15. LOD 的主要作用是？
A. 增加 DrawCall　B. 随距离降低模型细节　C. 只对 UI 有效　D. 替代遮挡剔除

  • 正确答案：B
  • 解析：LOD 根据距离切换不同精度网格，降低远处物体开销。

16. 视锥剔除的作用是？
A. 减少纹理　B. 减少动画　C. 剔除相机视野外的渲染对象　D. 压缩音频

  • 正确答案：C
  • 解析：视锥剔除避免提交相机看不到的对象，降低 DrawCall 与顶点处理。

17. 遮挡剔除适合什么场景？
A. 大量被墙体遮挡的静态物体　B. 所有 UI　C. 音频　D. 网络

  • 正确答案：A
  • 解析：遮挡剔除通过预计算或运行时判断对象是否被遮挡，减少无效渲染。

18. SetPass Call 表示？
A. 网络请求　B. GC 次数　C. 音频通道　D. 切换渲染状态/Pass 的次数

  • 正确答案：D
  • 解析：SetPass 数量反映渲染状态切换频率，通常越低越好。

19. SRP Batcher 与 GPU Instancing 的关系是？
A. 完全互斥不能共存　B. 解决不同问题，可配合使用　C. 完全相同　D. 只适用于 UI

  • 正确答案：B
  • 解析：SRP Batcher 降低材质设置开销，Instancing 批量绘制相同网格，两者可结合。

20. 渲染队列（Render Queue）决定什么？
A. 物体绘制顺序　B. 资源加载顺序　C. 脚本执行顺序　D. 网络顺序

  • 正确答案：A
  • 解析：Queue 决定不透明、透明、覆盖等物体的绘制顺序，透明物体尤其依赖排序。

21. 多 Pass Shader 的主要代价是？
A. 减少 DrawCall　B. 减少内存　C. 增加 Pass 与状态切换　D. 提升帧率

  • 正确答案：C
  • 解析：每个 Pass 都可能产生额外渲染开销，应尽量减少不必要的 Pass。

22. 后处理通常应在什么阶段执行？
A. 所有物体绘制前　B. 只对 UI　C. 只在 Editor　D. 场景渲染完成后、最终输出前

  • 正确答案：D
  • 解析：后处理对已渲染画面做全屏处理，通常在相机渲染完成后执行。

23. HDR 的主要作用是？
A. 提供更高动态范围的颜色信息　B. 减少纹理　C. 压缩音频　D. 提升网络

  • 正确答案：A
  • 解析：HDR 保留高亮信息，配合 Bloom、色调映射可得到更自然的光照。

24. 纹理图集的主要作用是？
A. 减少内存一定　B. 减少纹理切换与 DrawCall　C. 提升音频　D. 替代光照

  • 正确答案：B
  • 解析：图集把多张小图合并，减少纹理切换，但过大会增加内存与加载成本。

25. 实时阴影距离（Shadow Distance）调小的主要效果是？
A. 阴影更清晰　B. 增加 DrawCall　C. 减少远处阴影渲染开销　D. 提升音频

  • 正确答案：C
  • 解析：缩小阴影距离可减少阴影贴图覆盖范围与渲染对象数量。

26. 查看 GPU 各阶段耗时应使用？
A. Memory Profiler　B. CPU Profiler　C. Frame Debugger　D. GPU Profiler

  • 正确答案：D
  • 解析：GPU Profiler 可查看渲染各阶段耗时；Frame Debugger 更偏提交顺序。

27. 深度图常用于？
A. 深度测试、后处理与阴影等效果　B. 音频压缩　C. 网络同步　D. UI 布局

  • 正确答案：A
  • 解析：深度图记录像素深度，用于深度测试、SSAO、景深、阴影等。

28. 反射探针主要用于？
A. 压缩纹理　B. 提供环境反射信息　C. 减少 DrawCall　D. 动画

  • 正确答案：B
  • 解析：反射探针烘焙周围环境，为材质提供反射 Cubemap。

29. 以下哪项最可能阻止 GPU Instancing？
A. 相同 Mesh　B. 相同 Material　C. Shader 不支持 Instancing　D. 相同颜色

  • 正确答案：C
  • 解析：Shader 必须支持 Instancing，并满足网格、材质等条件。

30. URP 性能排查的合理顺序是？
A. 先改后处理　B. 先换模型　C. 先改分辨率　D. 先分 CPU/GPU，再看 DrawCall、Overdraw、Shader 与后处理

  • 正确答案：D
  • 解析：先确认瓶颈类型，再用 Frame Debugger/GPU Profiler 定位具体渲染问题。

二、主观题

1. 如何排查一个场景 DrawCall 过高？

  • 参考点：Frame Debugger、合批原因、材质/纹理、静态/动态合批、Instancing、SRP Batcher、阴影与后处理 Pass。

2. 移动端渲染优化有哪些优先级？

  • 参考点：分辨率、Overdraw、阴影、后处理、纹理压缩、LOD、剔除、Shader 复杂度、真机验证。

3. 如何控制 Shader Variants 数量？

  • 参考点：关键字裁剪、Stripping、Material 变体、Shader Graph 控制、构建报告、运行时加载策略。

4. SRP Batcher 为什么有时反而更慢？

  • 参考点：Shader 不兼容、频繁切换 Material、与 Instancing 冲突、CBUFFER 布局、状态切换。

5. 如何设计一个可维护的渲染性能规范？

  • 参考点：DrawCall/SetPass 预算、Overdraw 预算、纹理规范、Shader 规范、后处理开关、真机指标、CI 检查。
