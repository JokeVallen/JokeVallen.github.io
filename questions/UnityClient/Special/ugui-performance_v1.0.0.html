题卷版本：v1.0.0

本卷共 30 道客观题 + 5 道主观题，聚焦 UGUI / TMP 性能与工程实践。

建议： 先独立作答，再对照解析；错题直接录入「算法复盘」或补充知识卡片。

一、客观题

1. UGUI 的 Reconstruction 主要分为哪两类？
A. 物理重建与动画重建　B. 材质重建与音频重建　C. Layout Rebuild 与 Graphic Rebuild　D. 场景重建与资源重建

  • 正确答案：C
  • 解析：布局组件变化触发 Layout Rebuild，顶点、颜色、材质等变化触发 Graphic Rebuild；布局重建后通常还会连带图形重建。

2. 大量静态 UI 与频繁变化的动态 UI 最合理的组织方式是？
A. 拆分到不同 Canvas　B. 全部放在同一个 Canvas　C. 每帧重建整个 Canvas　D. 增加更多 Mask

  • 正确答案：A
  • 解析：Canvas 的批次重建会影响整个 Canvas，把动态部分拆出去可以缩小重建范围。

3. 以下哪项最可能打断 UGUI 合批？
A. 使用相同图集　B. 使用相同材质　C. 同级相邻元素　D. 中间插入 Stencil Mask

  • 正确答案：D
  • 解析：Mask 会切换 Stencil 渲染状态，可能导致合批中断；材质、纹理、Canvas 层级变化也会打断合批。

4. 滚动列表的矩形裁剪应优先使用？
A. Mask　B. RectMask2D　C. CanvasGroup　D. GraphicRaycaster

  • 正确答案：B
  • 解析：RectMask2D 只做矩形裁剪，不依赖 Stencil，通常比 Mask 更轻；异形裁剪才需要 Mask。

5. 装饰性图片和文本通常应该？
A. 关闭 raycastTarget　B. 全部开启 raycastTarget　C. 每帧重建　D. 强制使用 Mask

  • 正确答案：A
  • 解析：只有需要响应点击的 UI 才开启 raycastTarget，否则会增加 GraphicRaycaster 的遍历和排序成本。

6. ContentSizeFitter 与 LayoutGroup 互相依赖时最容易出现？
A. 自动合批　B. 纹理压缩　C. 反复布局重建　D. 网络延迟

  • 正确答案：C
  • 解析：父物体按子物体撑开、子物体又按父物体排列，容易形成布局循环和多次 Layout Rebuild。

7. 大列表使用 ScrollRect 时，推荐的做法是？
A. 一次性实例化全部 Item　B. 虚拟滚动 + 对象池　C. 每帧 ForceRebuildLayout　D. 所有 Item 使用不同 Canvas

  • 正确答案：B
  • 解析：虚拟滚动只创建可视区附近的单元格，滚动时复用，避免大量 GameObject 与布局计算。

8. CanvasGroup.blocksRaycasts = false 表示？
A. 隐藏 UI　B. 禁用动画　C. 销毁 UI　D. 组内元素不接收射线

  • 正确答案：D
  • 解析：它只影响射线检测，不改变视觉显示；隐藏应改 alpha 或 SetActive。

9. CanvasScaler 的 Scale With Screen Size 用于？
A. 按参考分辨率缩放 UI　B. 固定物理尺寸　C. 只处理刘海屏　D. 关闭所有缩放

  • 正确答案：A
  • 解析：该模式按参考分辨率和 Match 参数缩放 Canvas；安全区仍需单独处理。

10. UGUI 点击命中的最终决定因素是？
A. 代码执行顺序　B. 资源加载顺序　C. Canvas 排序、层级与射线结果　D. 纹理压缩格式

  • 正确答案：C
  • 解析：EventSystem 收集 Raycaster 命中并按深度排序，最上层且 raycastTarget 为 true 的元素优先接收事件。

11. TMP 动态字体图集扩容时最可能出现？
A. 没有任何开销　B. CPU 峰值与图集重建　C. 只影响音频　D. 自动降低分辨率

  • 正确答案：B
  • 解析：新增字形可能触发图集扩容与纹理重建，应预生成常用字符集并配置 Fallback。

12. 频繁更新 TMP 文本时，较低分配的做法是？
A. 每帧 text = new string　B. 每帧 ToString　C. 每帧重新创建 TMP 对象　D. 使用 SetText 或字符数组接口

  • 正确答案：D
  • 解析：TMP 提供 SetText、SetCharArray 等接口减少字符串分配；频繁改文本仍会触发 Graphic 重建。

13. SpriteAtlas 的主要作用是？
A. 减少纹理切换与 DrawCall　B. 压缩音频　C. 提升网络速度　D. 代替 Animator

  • 正确答案：A
  • 解析：图集把多张小图合并到一张纹理，减少纹理切换，但图集过大或频繁切换也会带来新问题。

14. 一个 UI Canvas 中 DrawCall 偏高，优先排查？
A. 音频采样率　B. 材质/纹理切换与合批打断　C. 网络延迟　D. 脚本编译时间

  • 正确答案：B
  • 解析：用 Frame Debugger 查看每个 Batch 为什么被打断，常见原因是图集不同、Mask、材质不同或层级穿插。

15. Overdraw 指的是？
A. 顶点数量过多　B. 纹理尺寸过大　C. 同一像素被多次绘制　D. 网络包重复

  • 正确答案：C
  • 解析：半透明 UI、粒子、重叠图片容易造成 Overdraw，移动端 GPU 填充率可能成为瓶颈。

16. 刘海屏内容适配应使用？
A. Screen.safeArea　B. Screen.width 固定值　C. 只调整 CanvasScaler　D. 忽略即可

  • 正确答案：A
  • 解析：背景铺满全屏，内容根节点映射到 Screen.safeArea，并在方向变化时刷新。

17. 多个 Canvas 的渲染顺序主要由什么决定？
A. 代码文件顺序　B. 资源包顺序　C. 组件添加顺序　D. Canvas 的 Sorting Order 与层级

  • 正确答案：D
  • 解析：Canvas 的 Sorting Layer、Sorting Order、Render Mode 与层级共同决定绘制顺序。

18. LayoutGroup 的性能优化方向是？
A. 每帧强制重建　B. 减少层级嵌套与频繁尺寸变化　C. 增加更多 ContentSizeFitter　D. 使用更多 Mask

  • 正确答案：B
  • 解析：布局组件嵌套越深、尺寸变化越频繁，Layout Rebuild 越贵；能用固定布局就避免动态计算。

19. GraphicRaycaster 的性能主要受什么影响？
A. 纹理压缩格式　B. 音频格式　C. 可接收射线的 Graphic 数量与层级复杂度　D. 网络协议

  • 正确答案：C
  • 解析：每次点击会收集并排序命中结果，raycastTarget 数量越多、层级越复杂，开销越大。

20. 使用 Mask 的主要代价是？
A. 增加 Stencil 状态切换，可能打断合批　B. 自动减少 DrawCall　C. 降低纹理内存　D. 提升帧率

  • 正确答案：A
  • 解析：Mask 使用模板测试，可能让子元素拆成额外批次；矩形场景应优先 RectMask2D。

21. UI 淡入淡出优先使用？
A. 每帧 SetActive　B. 每帧重建 Layout　C. 每帧修改 RectTransform 尺寸　D. CanvasGroup.alpha

  • 正确答案：D
  • 解析：CanvasGroup.alpha 统一控制一组 UI 的透明度，比逐个改 Graphic 更方便；仍应避免无意义的高频变化。

22. 弹窗管理最合理的方式是？
A. 每个业务自己 Instantiate　B. 统一 UIManager 管理栈、层级与生命周期　C. 所有弹窗做成单例　D. 不用遮罩

  • 正确答案：B
  • 解析：统一管理可以处理打开顺序、遮罩、返回键、缓存、防重复打开和异步加载。

23. UI 红点系统应优先采用什么结构？
A. 树形依赖 + 事件驱动刷新　B. 每帧遍历所有红点　C. 每个红点单独 Update　D. 只用静态布尔值

  • 正确答案：A
  • 解析：红点通常有父子依赖，树形路径注册和事件驱动可以避免每帧全量遍历。

24. 临时隐藏一个仍需保留状态的 UI，较推荐？
A. Destroy　B. 每帧 SetActive 切换　C. CanvasGroup.alpha 或 blocksRaycasts 控制　D. 清空 Canvas

  • 正确答案：C
  • 解析：CanvasGroup 可以隐藏或禁用交互而保留对象状态；频繁 SetActive 可能触发布局与重建。

25. UI 元素频繁改变位置时，优先考虑？
A. 每帧 ForceRebuildLayout　B. 使用独立 Canvas 或直接改 RectTransform　C. 增加 LayoutGroup　D. 增加 Mask

  • 正确答案：B
  • 解析：直接修改 Transform 通常比触发布局系统更轻；频繁变化的部分拆到独立 Canvas 可减少影响范围。

26. 中文 UI 文本使用 TMP 时，最重要的资源准备是？
A. 只使用默认字体　B. 关闭所有字体图集　C. 每帧生成新字体　D. 预生成常用字符集并配置 Fallback

  • 正确答案：D
  • 解析：中文常用字多，运行时动态扩图容易产生峰值；应预生成常用字符并配置后备字体。

27. 图片既被 SpriteAtlas 包含又被单独引用，可能导致？
A. 资源重复打包　B. 自动减少包体　C. 提升帧率　D. 自动压缩音频

  • 正确答案：A
  • 解析：同时被图集和单独引用时，打包器可能各打一份，造成包体与内存冗余。

28. 同一 Canvas 中相邻 UI 元素无法合批，最不可能的原因是？
A. 纹理不同　B. 材质不同　C. 代码命名不同　D. 中间插入 Mask

  • 正确答案：C
  • 解析：变量名、类名不影响渲染；材质、纹理、渲染状态和层级才会影响合批。

29. UGUI 按钮点击推荐实现方式是？
A. 每个按钮用 Update 检测鼠标　B. 实现 IPointerClickHandler 或使用 Button.onClick　C. 每帧射线检测　D. 只用 OnMouseDown

  • 正确答案：B
  • 解析：UGUI 的事件系统按需派发点击事件，不需要每帧检测；移动端触摸也统一由 EventSystem 处理。

30. 排查 UI 卡顿的合理顺序是？
A. 先换字体　B. 先加更多 Canvas　C. 先关闭所有 UI　D. Profiler 定位 CPU/GC/重建，再用 Frame Debugger 看渲染

  • 正确答案：D
  • 解析：先用 Profiler 区分脚本、GC、布局重建、渲染还是 GPU，再针对性优化，避免盲目改参数。

二、主观题

1. 一个 1000 项的排行榜列表滚动卡顿，如何优化？

  • 参考点：虚拟列表、对象池、可视区计算、避免 LayoutGroup 全量重建、RectMask2D、数据绑定复用、滚动节流。

2. Canvas 重建导致 CPU 峰值，如何定位和拆分？

  • 参考点：Profiler 看 Canvas.SendWillRenderCanvases、区分 Layout/Graphic、拆分静态与动态 Canvas、减少尺寸变化、检查 ContentSizeFitter。

3. TMP 中文字体图集频繁扩容，如何处理？

  • 参考点：预生成字符集、Atlas 尺寸、Fallback、按语言拆分、避免运行时随机生僻字、监控图集重建。

4. UI 中 DrawCall 很高，如何用 Frame Debugger 分析？

  • 参考点：逐个 Batch 查看打断原因、图集/材质/Mask/Sorting、合并图集、调整层级、减少全屏遮罩。

5. 设计一套 UI 性能验收规范。

  • 参考点：Canvas 数量与拆分规则、raycastTarget 规范、图集规范、列表必须虚拟化、Overdraw 预算、TMP 字符集、真机帧率与内存指标、CI 检查。
