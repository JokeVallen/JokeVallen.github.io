Addressables / AssetBundle 专项卷（一）

30 道客观题 + 5 道主观题，聚焦资源加载、依赖、卸载与热更新。

答题记录

暂无记录，完成一次批卷后会生成。

一、客观题

1. Addressables 相比直接使用 AssetBundle，主要增加了什么能力？

A自动生成全部纹理图集
B封装 Catalog 与引用计数
C自动压缩全部音频资源
D直接替代全部脚本编译
查看答案与解析

正确答案：B

Addressables 在 AB 之上封装了 Catalog、异步加载、远程更新和引用计数。

反馈本题

2. 释放 Addressables 资源句柄应使用哪个接口？

A调用 Destroy(handle)
B调用 GC.Collect()
C调用 Release(handle)
D调用 UnloadUnusedAssets
查看答案与解析

正确答案：C

Release 减少引用计数，计数归零后资源才可能卸载。

反馈本题

3. 通过 InstantiateAsync 创建的实例应如何释放？

A只调用 Destroy(go)
B调用 ReleaseInstance(go)
C只调用 Release(handle)
D不需要主动释放
查看答案与解析

正确答案：B

ReleaseInstance 会归还实例并正确减少引用计数。

反馈本题

4. 获取一个 AssetBundle 的全部依赖包应使用？

AAssetBundle.LoadFromFile
BAssetBundle.Unload(false)
CManifest.GetAllDependencies
DResources.LoadAll
查看答案与解析

正确答案：C

Manifest 记录包依赖，加载资源前必须先加载依赖包。

反馈本题

5. 关于 AssetBundle.Unload(true)，以下说法不正确的是？

A会销毁已加载的 Asset
B可能造成场景资源丢失
C会保留所有实例引用
D会释放包内资源对象
查看答案与解析

正确答案：C

Unload(true) 会销毁 Asset，并不会保留实例引用；仍在使用的资源可能变成 Missing。

反馈本题

6. AssetBundle 资源冗余的常见原因是？

A共享资源未提取公共包
B包体整体太小
C没有使用 LZ4 压缩
D没有开启 Mipmap
查看答案与解析

正确答案：A

多个包各自包含同一份共享资源，会导致包体和内存重复。

反馈本题

7. Addressables 远程资源更新后，客户端通常需要？

A重新安装整个应用
B删除全部本地缓存
C关闭 CDN 网络
D更新 Catalog 后加载
查看答案与解析

正确答案：D

Catalog 是资源地址和版本索引，内容更新需要同步更新 Catalog。

反馈本题

8. Addressables Group 的 Schema 主要配置什么？

A脚本编译选项
B字体图集参数
C打包与更新规则
D网络通信协议
查看答案与解析

正确答案：C

Group Schema 决定 Bundle Mode、内容更新和压缩方式等打包规则。

反馈本题

9. Sprite 被重复打包进多个包，可能是因为？

A图集尺寸过大
B图集与单独引用并存
C未使用 ASTC 压缩
D未开启 Mipmap
查看答案与解析

正确答案：B

同一资源被图集和单独引用同时包含时，容易重复打包。

反馈本题

10. 纹理开启 Read/Write 的主要影响是？

A增加 CPU 内存副本
B减少运行时内存
C自动提升压缩率
D只影响音频资源
查看答案与解析

正确答案：A

Read/Write 允许 CPU 访问纹理，但会保留额外内存副本。

反馈本题

11. ASTC 主要用于什么场景？

A音频压缩编码
B网络协议传输
C移动端纹理压缩
DUI 布局计算
查看答案与解析

正确答案：C

ASTC 是移动端常用纹理压缩格式，按块大小权衡质量与体积。

反馈本题

12. 短促、高频的 UI 音效最适合哪种 Load Type？

AStreaming
BCompressed In Memory
C三种完全一样
DDecompress On Load
查看答案与解析

正确答案：D

短音效解压后常驻内存，播放 CPU 开销低；长音乐才用 Streaming。

反馈本题

13. LZMA 与 LZ4 的典型取舍是？

ALZMA 更小但解压慢
B两者压缩率完全一样
CLZ4 包体一定更小
DLZMA 不能用于移动端
查看答案与解析

正确答案：A

LZMA 压缩率高但解压慢，LZ4 加载快，适合运行时使用。

反馈本题

14. AssetBundle Variant 的典型用途是？

A控制脚本编译顺序
B区分多分辨率资源
C压缩全部音频
D自动生成字体
查看答案与解析

正确答案：B

Variant 用于同一逻辑资源的不同版本，例如高清与低清。

反馈本题

15. LoadAssetAsync 与 InstantiateAsync 的主要区别是？

A前者只能加载场景
B后者只能加载配置
C前者共享，后者实例
D两者完全一样
查看答案与解析

正确答案：C

LoadAssetAsync 返回共享资源，InstantiateAsync 创建独立实例。

反馈本题

16. 运行时使用 WaitForCompletion 的主要问题是？

A一定编译失败
B只能用于音频
C不会释放资源
D会阻塞主线程
查看答案与解析

正确答案：D

同步等待异步操作完成可能造成明显卡顿，只适合极少数启动场景。

反馈本题

17. 关于 Addressables 引用计数，以下说法不正确的是？

A加载会增加引用计数
BRelease 会减少计数
C归零后才可能卸载
D归零后必定立即卸载
查看答案与解析

正确答案：D

计数归零只是具备卸载条件，并不保证立即卸载。

反馈本题

18. AssetBundle Manifest 的主要作用是？

A存储全部音频
B记录依赖与哈希
C生成 UI 界面
D编译 Shader
查看答案与解析

正确答案：B

Manifest 描述包之间的依赖和资源信息，是加载依赖与版本校验的依据。

反馈本题

19. 大量使用 Resources.Load 的主要问题是？

A加载速度太快
B自动完成热更
C无法热更且常驻包体
D不能加载 Prefab
查看答案与解析

正确答案：C

Resources 资源全部打进安装包，无法热更，引用关系也不透明。

反馈本题

20. StreamingAssets 的典型特点是？

A原样打包可路径读取
B自动压缩和热更
C只能存放脚本
D必须通过 Resources 加载
查看答案与解析

正确答案：A

StreamingAssets 不参与资源导入流程，适合按路径读取视频、配置等文件。

反馈本题

21. 热更新方案中，程序集热更主要解决什么？

A纹理压缩问题
BUI 合批问题
C网络同步问题
DC# 逻辑更新
查看答案与解析

正确答案：D

资源热更只能更新资源，程序集热更用于更新 C# 逻辑。

反馈本题

22. HybridCLR 的主要特点是？

A只能热更资源
BAOT 加解释器
C只能用于 Android
D不需要构建流程
查看答案与解析

正确答案：B

HybridCLR 通过 AOT 与解释器结合补足动态代码能力，适合纯 C# 热更。

反馈本题

23. link.xml 在 IL2CPP 项目中的作用是？

A防止裁剪反射类型
B压缩纹理资源
C配置网络协议
D自动生成图集
查看答案与解析

正确答案：A

IL2CPP 会裁剪未直接引用的代码，反射或热更用到的类型需要用 link.xml 保留。

反馈本题

24. 远程内容更新后，客户端首先需要做什么？

A只替换本地图片
B只清空本地缓存
C下载新的 Catalog
D关闭 CDN 服务
查看答案与解析

正确答案：C

客户端需要先获取新 Catalog，才能定位更新后的资源包。

反馈本题

25. AssetBundle 加密的主要代价是？

A包体自动变小
B加载自动变快
C不需要版本管理
D增加调试兼容成本
查看答案与解析

正确答案：D

加密会增加解密开销、调试难度和平台兼容成本。

反馈本题

26. AssetBundle 的 CRC 与版本号主要用于？

A生成 UI 界面
B校验完整与版本
C压缩音频资源
D编译 C# 脚本
查看答案与解析

正确答案：B

CRC 检测包损坏，版本号确保加载正确的资源版本。

反馈本题

27. Addressables 预热（Preload）的主要目的是？

A减少首次加载卡顿
B增加安装包体
C自动完成热更
D降低全部内存
查看答案与解析

正确答案：A

提前加载常用资源可以把卡顿从关键路径前移或摊平。

反馈本题

28. 排查资源泄漏时，以下做法不推荐的是？

A抓取内存快照对比
B通过引用链找持有者
C只看当前帧率
D检查句柄是否释放
查看答案与解析

正确答案：C

帧率无法定位资源持有关系，应使用 Memory Profiler 查引用链。

反馈本题

29. AssetBundle 构建报告主要用于？

A生成 UI 界面
B分析包体与依赖
C编译 Shader
D播放音频资源
查看答案与解析

正确答案：B

构建报告能看出包体大小、资源分布和重复依赖。

反馈本题

30. 资源分包的合理原则是？

A所有资源打成一个大包
B每个文件单独一个包
C只按文件扩展名分
D按模块与更新频率分
查看答案与解析

正确答案：D

分包要兼顾加载频率、依赖关系、更新范围和包体大小。
