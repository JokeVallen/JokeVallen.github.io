一、客观题

C# 异步与运行时

1. 在 Unity 主线程代码中使用 ConfigureAwait(false) 的风险是？
A. 一定编译失败　B. 会自动提升 UI 性能　C. 后续代码可能不在主线程，访问 Unity API 不安全　D. 只能用于 Task.Delay

  • 正确答案：C
  • 解析：ConfigureAwait(false) 允许后续延续在线程池执行，之后访问 Transform、GameObject 等 Unity API 可能抛异常。

2. 调用 CancellationTokenSource.Cancel() 后，已注册的回调通常会？
A. 被触发执行　B. 自动销毁对象　C. token 自动重置　D. 无法再创建新的 CTS

  • 正确答案：A
  • 解析：取消会同步触发已注册回调，业务回调中应避免执行阻塞或重入操作。

3. 在 Task.Run 中直接访问 transform.position 会怎样？
A. 完全支持　B. Unity 自动切回主线程　C. 只在 Editor 报错　D. 不允许，Unity API 通常只能在主线程访问

  • 正确答案：D
  • 解析：Unity 大部分 API 不是线程安全的，需要把结果切回主线程后再更新场景对象。

4. UniTask 相比原生 Task 的主要优势是？
A. 只能配合协程使用　B. 与 Unity PlayerLoop 集成且分配更低　C. 不需要取消　D. 支持多线程渲染

  • 正确答案：B
  • 解析：UniTask 针对 Unity 优化，支持 PlayerLoop、低分配、取消和丰富的组合操作。

5. async 方法中的 finally 在取消或异常时？
A. 永远不执行　B. 只在成功时执行　C. 通常仍会执行　D. 只能用于 Task

  • 正确答案：C
  • 解析：finally 用于清理资源，异常与取消路径通常也会执行，但要注意取消后不要继续访问已销毁对象。

6. IDisposable 与 finalizer 的关系是？
A. Dispose 主动释放，finalizer 由 GC 调用　B. 两者完全等价　C. finalizer 一定先执行　D. struct 不能实现 IDisposable

  • 正确答案：A
  • 解析：Dispose 由调用方及时释放；finalizer 执行时机不确定，不应依赖它清理 Unity 对象。

7. 关于 ValueTask，正确的说法是？
A. 可以任意多次 await　B. 通常只消费一次　C. 只能返回 void　D. 不支持取消

  • 正确答案：B
  • 解析：ValueTask 是为减少分配设计的，多次 await 或重复消费可能触发未定义行为。

8. 关于 Span<T>，正确的是？
A. 可以作为类字段　B. 可以跨 await　C. 可以装箱　D. 是 ref struct，只能存在于栈上

  • 正确答案：D
  • 解析：Span<T> 不能装箱、不能作为类字段、不能跨 await 保留。

9. WeakReference<T> 的特点是？
A. 不阻止 GC 回收目标对象　B. 线程安全集合　C. 只能存值类型　D. 强引用对象

  • 正确答案：A
  • 解析：弱引用适合缓存和监听器表，使用前需 TryGetTarget 检查对象是否还存活。

10. Interlocked.Increment 的作用是？
A. 加锁　B. 序列化对象　C. 原子自增　D. 反射调用

  • 正确答案：C
  • 解析：Interlocked 提供原子操作，适合无锁计数，但不能替代复杂临界区锁。

Unity 生命周期

11. 在 OnDestroy 中启动协程通常会怎样？
A. 正常执行到底　B. 对象销毁后协程无法正常执行　C. 一定编译报错　D. 自动延迟到下一帧

  • 正确答案：B
  • 解析：对象销毁后协程宿主不存在，启动协程可能无效；清理逻辑应直接执行。

12. DontDestroyOnLoad 的正确理解是？
A. 自动创建单例　B. 自动清理重复对象　C. 只对 UI 有效　D. 切场景保留对象，需要自己防重复

  • 正确答案：D
  • 解析：它只保证对象不随场景销毁，单例去重和生命周期管理仍需自己处理。

13. Awake 与 Start 的执行时机是？
A. Awake 在对象激活时，Start 在首次 Update 前　B. Start 先于 Awake　C. 两者同时　D. 完全随机

  • 正确答案：A
  • 解析：Awake 用于初始化自身引用，Start 在第一帧 Update 前执行，适合依赖其他对象初始化完成后的逻辑。

14. 运行时直接修改 ScriptableObject 资产可能导致？
A. 完全无影响　B. 每次运行自动重置　C. Editor 中污染资产　D. 只能保存字符串

  • 正确答案：C
  • 解析：ScriptableObject 是资产，运行时修改可能写回 Editor 资产；只读配置应使用运行时副本。

15. Additive 加载场景后，SetActiveScene 主要影响？
A. 自动卸载旧场景　B. 新对象归属与光照设置　C. 不能同时加载多个场景　D. 只影响 UI

  • 正确答案：B
  • 解析：活动场景决定新对象默认归属，也影响光照和天空盒等设置。

16. Physics.OverlapSphereNonAlloc 的优势是？
A. 一定更快　B. 只能用于 2D　C. 不会返回结果　D. 复用数组减少 GC

  • 正确答案：D
  • 解析：NonAlloc 版本要求调用方传入数组，避免每次调用分配新数组；结果数量以返回值表示。

17. Animator 的 Cull Completely 表示？
A. 不可见时完全停止更新　B. 每帧都更新　C. 只剔除阴影　D. 只对 UI 有效

  • 正确答案：A
  • 解析：不可见时停止动画更新，可降低 CPU；重新可见时需要正确恢复状态。

18. LoadSceneAsync 设置 allowSceneActivation = false 后？
A. 立即激活　B. 无法加载　C. 加载到约 0.9 后等待激活　D. 只加载 UI

  • 正确答案：C
  • 解析：常用于加载界面与进度条，加载到约 0.9 后等待手动激活。

19. Object.Destroy 与 DestroyImmediate 的区别是？
A. 完全等价　B. Destroy 延迟到帧末，DestroyImmediate 立即执行且不建议运行时使用　C. 只能用于 Editor　D. 两者都异步

  • 正确答案：B
  • 解析：运行时优先使用 Destroy，避免在遍历或回调中立即销毁造成引用失效。

20. Time.timeScale = 0 时？
A. 所有 Update 停止　B. FixedUpdate 正常执行　C. 所有协程停止　D. 基于缩放时间的逻辑暂停，Unscaled 仍运行

  • 正确答案：D
  • 解析：timeScale 影响 deltaTime 与基于缩放时间的协程，unscaledDeltaTime 和 WaitForSecondsRealtime 不受影响。

UI 架构

21. UI 弹窗管理的合理方式是？
A. 统一 UIManager 管理栈、层级与生命周期　B. 每个业务自己 Instantiate　C. 所有弹窗做成单例　D. 完全不做管理

  • 正确答案：A
  • 解析：统一管理可处理打开顺序、遮罩、返回键、缓存、防重复打开和异步加载。

22. 异步打开 UI 返回时界面已被关闭，应该？
A. 继续显示　B. 让程序崩溃　C. 检查取消令牌/打开版本，再决定是否显示　D. 完全忽略

  • 正确答案：C
  • 解析：异步加载期间界面状态可能变化，必须在回调中校验请求是否仍然有效。

23. UI 事件订阅的最佳退订时机是？
A. 不需要退订　B. OnDisable 或 OnDestroy　C. 每帧退订　D. 退出游戏时

  • 正确答案：B
  • 解析：订阅与退订应成对出现，避免对象销毁后事件中心仍持有引用。

24. CanvasGroup.blocksRaycasts = false 表示？
A. 组内元素不接收射线　B. 视觉隐藏　C. 销毁对象　D. 禁用动画

  • 正确答案：A
  • 解析：它只影响射线检测，不改变显示。

25. 静态 UI 与频繁变化的动态 UI 应？
A. 放在同一 Canvas　B. 增加更多 Mask　C. 每帧重建　D. 拆分到不同 Canvas

  • 正确答案：D
  • 解析：独立 Canvas 可缩小批次重建范围。

26. TMP 动态字体图集扩容可能造成？
A. 无任何开销　B. 只在 Editor 发生　C. CPU 峰值与图集重建　D. 自动压缩音频

  • 正确答案：C
  • 解析：新增字形触发图集重建，应预生成常用字符并配置 Fallback。

27. ScrollRect 大列表推荐？
A. 一次性实例化全部 Item　B. 虚拟滚动 + 对象池　C. 每帧重建布局　D. 禁用 Mask

  • 正确答案：B
  • 解析：只创建可视区域附近的单元格，滚动时复用。

28. 装饰性 UI 元素通常应？
A. 关闭 raycastTarget　B. 全部开启 raycastTarget　C. 每帧刷新　D. 强制使用 Mask

  • 正确答案：A
  • 解析：只有需要响应点击的元素才开启 raycastTarget。

29. UI 点击穿透最可能的原因是？
A. 网络延迟　B. 音频格式　C. 纹理压缩　D. 上层遮罩、raycastTarget 或层级问题

  • 正确答案：D
  • 解析：用 EventSystem 射线结果、Canvas 层级与 raycastTarget 定位。

30. 刘海屏内容适配应使用？
A. 只处理 iOS　B. Screen.safeArea 映射内容根节点　C. 硬编码偏移　D. 依赖 CanvasScaler 自动完成

  • 正确答案：B
  • 解析：背景铺满全屏，内容根节点映射到安全区，并在方向变化时刷新。

资源与热更

31. Addressables 释放资源应使用？
A. Destroy(handle)　B. GC.Collect　C. Addressables.Release(handle)　D. 只 UnloadUnusedAssets

  • 正确答案：C
  • 解析：Release 减少引用计数，计数归零后才可能卸载。

32. Addressables.InstantiateAsync 的实例应？
A. Addressables.ReleaseInstance(go)　B. 只 Destroy(go)　C. 只 Release(handle)　D. 不释放

  • 正确答案：A
  • 解析：实例需要 ReleaseInstance 正确归还实例与引用计数。

33. AssetBundle Unload(true) 的风险是？
A. 一定安全　B. 只卸载依赖　C. 不释放内存　D. 可能卸载正在使用的资源

  • 正确答案：D
  • 解析：强制卸载已加载 Asset 会导致场景引用变成 Missing。

34. 图集资源重复打包的常见原因是？
A. 图集太大　B. 精灵同时被图集和单独引用　C. 没有 Mipmap　D. 使用 ASTC

  • 正确答案：B
  • 解析：同一资源被不同引用路径包含时可能重复打包。

35. 纹理开启 Read/Write 的主要影响是？
A. 增加 CPU 内存副本　B. 减少内存　C. 提升压缩率　D. 只影响 UI

  • 正确答案：A
  • 解析：需要 CPU 访问纹理时会保留额外副本，不需要时关闭。

36. 短促高频音效适合的 Load Type 是？
A. Streaming　B. Compressed In Memory　C. Decompress On Load　D. 无差别

  • 正确答案：C
  • 解析：短音效解压常驻，播放 CPU 开销低；长音乐用 Streaming。

37. HybridCLR 主要解决？
A. 资源压缩　B. C# 热更与 AOT 泛型　C. UI 合批　D. 网络同步

  • 正确答案：B
  • 解析：HybridCLR 通过 AOT + 解释器混合方案支持 C# 热更。

38. 排查资源泄漏首要看？
A. 显卡型号　B. 分辨率　C. 帧率　D. 引用链

  • 正确答案：D
  • 解析：引用链能说明谁仍持有资源，是定位泄漏的关键。

39. 加载 AssetBundle 资源前应先？
A. 通过 Manifest 加载依赖包　B. 直接 LoadAsset　C. 调用 GC　D. 清空 PlayerPrefs

  • 正确答案：A
  • 解析：先加载依赖，否则可能出现资源缺失或材质丢失。

40. Addressables 的 WaitForCompletion 适合？
A. 常规加载　B. 所有异步流程　C. 仅测试或极少数启动场景　D. 自动卸载

  • 正确答案：C
  • 解析：它会阻塞主线程，常规流程应使用异步等待。

性能

41. DrawCall 与 SetPass 的关系是？
A. 完全相等　B. 一个 SetPass 可能对应多个 DrawCall　C. SetPass 越多越好　D. 只和 UI 有关

  • 正确答案：B
  • 解析：SetPass 是渲染状态切换，多个 DrawCall 可能共享一个 SetPass。

42. 静态合批的限制是？
A. 移动物体也能合　B. 任意材质都能合　C. 只对 UI 有效　D. 物体不能移动，并受材质、顶点数、平台限制

  • 正确答案：D
  • 解析：静态合批把静态网格合并成大网格，移动物体不适用。

43. Overdraw 指的是？
A. 同一像素被多次绘制　B. 顶点数量太多　C. 内存不足　D. 网络延迟

  • 正确答案：A
  • 解析：半透明 UI、粒子和重叠模型是常见 Overdraw 来源。

44. 以下哪些是常见 GC 分配来源？
A. 仅 new GameObject　B. 仅 Resources.Load　C. string 拼接、LINQ、闭包、装箱　D. 仅网络消息

  • 正确答案：C
  • 解析：这些都会产生托管堆分配，应减少热点路径上的使用。

45. Memory Profiler 主要用于？
A. 帧率　B. 内存快照与引用链　C. 网络包　D. 编译 Shader

  • 正确答案：B
  • 解析：Memory Profiler 可抓取快照、对比差异并查看对象引用关系。

46. Frame Debugger 主要用于？
A. 逐 DrawCall/Batch 查看渲染过程　B. 查看 C# 调用栈　C. 查看网络包　D. 查看 GC

  • 正确答案：A
  • 解析：用于定位批次打断、渲染状态和 DrawCall 问题。

47. 启动优化的合理方向是？
A. 每帧调用 GC　B. 全部改用 Resources　C. 增加粒子特效　D. 延迟加载、资源拆包、异步初始化

  • 正确答案：D
  • 解析：减少首屏依赖、并行异步加载、延后非必要系统初始化。

48. 为什么需要真机 Profiling？
A. 不需要　B. Editor 与真机完全一致　C. 真机性能、发热和降频与 Editor 差异很大　D. 只用于 UI

  • 正确答案：C
  • 解析：Editor 不能代表移动端 CPU/GPU、内存带宽和热降频表现。

49. 对象池设计的关键是？
A. 无限增长　B. 重置状态并设置容量上限　C. 每次重新 new　D. 只用于 UI

  • 正确答案：B
  • 解析：复用必须清理状态并限制容量，避免内存持续增长。

50. LOD 的作用是？
A. 随距离降低模型细节　B. 增加 DrawCall　C. 只用于 UI　D. 替代遮罩

  • 正确答案：A
  • 解析：LOD 根据距离切换不同精度网格，降低远处物体的渲染开销。

网络

51. TCP 粘包的常见处理方式是？
A. 增加睡眠　B. 关闭 Nagle　C. 改用 UDP 一定解决　D. 长度前缀、分隔符或固定长度

  • 正确答案：D
  • 解析：TCP 是字节流，必须由应用层定义消息边界。

52. 帧同步与状态同步的主要区别是？
A. 完全一样　B. 帧同步传输入，状态同步传状态　C. 帧同步适合所有游戏　D. 状态同步不需要服务器

  • 正确答案：B
  • 解析：帧同步由客户端确定性演算，状态同步由服务器下发权威状态。

53. 网络心跳的主要作用是？
A. 检测连接存活与 NAT 超时　B. 压缩资源　C. 提升帧率　D. 加密协议

  • 正确答案：A
  • 解析：心跳保持连接活跃，及时发现断线并防止 NAT 映射超时。

54. Protobuf 的主要优势是？
A. 人类可读　B. 不需要 schema　C. 体积小、序列化快、跨语言　D. 只能用于 C#

  • 正确答案：C
  • 解析：Protobuf 使用二进制编码和 schema，适合网络协议。

55. 断线重连设计的关键是？
A. 直接重启客户端　B. 会话恢复、状态同步、幂等重发　C. 清空存档　D. 关闭心跳

  • 正确答案：B
  • 解析：重连需要恢复会话、补齐状态，并保证重复请求无副作用。

56. WebSocket 的特点是？
A. 只能 UDP　B. 不能加密　C. 只能客户端发送　D. 全双工长连接，适合实时消息

  • 正确答案：D
  • 解析：WebSocket 基于 HTTP 升级，支持全双工通信，常用于实时聊天和推送。

架构与工程

57. 事件总线最常见的问题是？
A. 订阅未退订导致泄漏或重复回调　B. 线程安全　C. 不能传参　D. 只能用于 UI

  • 正确答案：A
  • 解析：订阅者销毁后未反注册，事件中心仍持有引用。

58. 热更新版本管理的关键是？
A. 只更新客户端　B. 不需要 CDN　C. 资源与代码版本一致且可回滚　D. 不需要校验

  • 正确答案：C
  • 解析：必须保证程序集、资源、配置版本匹配，并提供下载校验、灰度与回滚。

59. 技术方案评审最应关注？
A. 只选最新技术　B. 性能、维护性、风险与回滚　C. 代码行数　D. 个人偏好

  • 正确答案：B
  • 解析：高级工程师要综合评估方案的上线风险、维护成本和失败回滚。

60. 团队协作中提升工程质量的合理方式是？
A. 只靠口头沟通　B. 不写文档　C. 不分模块　D. 规范、Code Review、自动化与文档

  • 正确答案：D
  • 解析：规范与自动化能降低沟通成本和回归风险，文档则保证知识可传递。

二、主观题

1. 设计一个支持取消、超时和重试的异步请求层。

  • 参考点：CancellationToken、超时、重试退避、幂等、异常分类、主线程回调、生命周期取消、日志与埋点。

2. 如何设计一个可测试的 UI 架构？

  • 参考点：View/Presenter/Model 分离、依赖注入、接口抽象、纯 C# 逻辑、Mock 数据、事件解耦、生命周期管理。

3. 如何解决 UI 弹窗异步加载的竞态问题？

  • 参考点：请求版本号、取消令牌、防重复打开、关闭状态校验、句柄释放、回调中检查对象有效性。

4. 如何设计一套资源加载与释放规范？

  • 参考点：统一 API、引用计数、句柄生命周期、缓存策略、异常处理、Editor 模拟、泄漏检测、资源审计。

5. 线上出现内存持续上涨，如何排查？

  • 参考点：Memory Profiler 快照对比、引用链、事件订阅、Addressables 句柄、静态集合、对象池、场景切换、资源审计。

6. 如何设计一个支持回滚的热更系统？

  • 参考点：版本清单、双版本目录、下载校验、灰度、启动自检、失败回退、强更策略、日志上报。

7. 如何做 UI 性能治理？

  • 参考点：Canvas 拆分、raycastTarget 规范、图集、TMP 字符集、列表虚拟化、Overdraw 预算、Profile 工具、真机验收。

8. 如何设计断线重连与状态恢复？

  • 参考点：会话 token、重连退避、状态版本、增量同步、幂等消息、超时处理、弱网测试。

9. 如何设计模块化工程结构？

  • 参考点：分层、asmdef、接口隔离、事件通信、依赖方向、模块生命周期、编译速度、可测试性。

10. 如何制定代码规范与 Code Review 清单？

  • 参考点：命名、目录、异常处理、事件退订、资源释放、性能红线、空引用、线程、日志、测试、Review 重点。

11. 如何评估一个 Unity 技术方案的可行性？

  • 参考点：性能、兼容性、团队能力、维护成本、上线风险、回滚能力、开发周期、跨平台。

12. 如何设计跨平台 SDK 接入层？

  • 参考点：统一接口、平台实现、JNI/OC 桥接、回调线程、权限、生命周期、Editor Mock、异常降级。
