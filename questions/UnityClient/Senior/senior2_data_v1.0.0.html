一、客观题

1. 在 Unity 主线程代码中使用 `ConfigureAwait(false)` 的风险是？ A. 一定编译失败　B. 会自动提升 UI 性能　C. 后续代码可能不在主线程，访问 Unity API 不安全　D. 只能用于 `Task.Delay`

A一定编译失败
B会自动提升 UI 性能
C后续代码可能不在主线程，访问 Unity API 不安全
D只能用于 `Task.Delay`
查看答案与解析

正确答案：C

`ConfigureAwait(false)` 允许后续延续在线程池执行，之后访问 Transform、GameObject 等 Unity API 可能抛异常。 {% endhideBlock %}

反馈本题

2. 调用 `CancellationTokenSource.Cancel()` 后，已注册的回调通常会？ A. 被触发执行　B. 自动销毁对象　C. token 自动重置　D. 无法再创建新的 CTS

B自动销毁对象
Ctoken 自动重置
D无法再创建新的 CTS
查看答案与解析

正确答案：A

取消会同步触发已注册回调，业务回调中应避免执行阻塞或重入操作。 {% endhideBlock %}

反馈本题

3. 在 `Task.Run` 中直接访问 `transform.position` 会怎样？ A. 完全支持　B. Unity 自动切回主线程　C. 只在 Editor 报错　D. 不允许，Unity API 通常只能在主线程访问

D不允许，Unity API 通常只能在主线程访问
查看答案与解析

正确答案：D

Unity 大部分 API 不是线程安全的，需要把结果切回主线程后再更新场景对象。 {% endhideBlock %}
