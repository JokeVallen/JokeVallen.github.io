一、客观题

1. 在 Unity 中使用 `async void` 的主要风险是？ A. 一定无法编译　B. 异常无法被外层 try/catch 捕获　C. 只能用于 UI 事件　D. 不支持 await

A一定无法编译
B异常无法被外层 try/catch 捕获
C只能用于 UI 事件
D不支持 await
查看答案与解析

正确答案：B

`async void` 没有可等待的 Task，异常会直接抛到 SynchronizationContext，调用方无法用普通 try/catch 捕获。Unity 中应优先使用 `async UniTaskVoid` 或 `async Task`。 {% endhideBlock %}

反馈本题

2. 关于 `Span<T>`，下列说法正确的是？ A. 可以存入 `List<Span<int>>`　B. 可以跨 `await` 保存　C. 是 ref struct，不能装箱、不能作为类字段　D. 只能用于只读字符串

A可以存入 `List<Span<int>>`
B可以跨 `await` 保存
C是 ref struct，不能装箱、不能作为类字段
D只能用于只读字符串
查看答案与解析

正确答案：C

`Span<T>` 是 `ref struct`，只能存在于栈上，不能装箱、不能作为类字段、不能跨 `await` 保留。 {% endhideBlock %}

反馈本题

3. 把一个可变对象作为 `Dictionary` 的 key 后修改了参与 `GetHashCode` 的字段，最可能发生什么？ A. 通常再也找不到该项　B. Dictionary 自动重新哈希　C. 一定立即抛异常　D. Dictionary 自动重新排序

A通常再也找不到该项
BDictionary 自动重新哈希
C一定立即抛异常
DDictionary 自动重新排序
查看答案与解析

正确答案：A

Dictionary 用哈希值定位桶。key 的哈希变化后，查找会去错误的桶，导致找不到原项。key 应使用不可变对象或稳定哈希。 {% endhideBlock %}

反馈本题

4. 关于 `GC.Collect`，正确的做法是？ A. 每帧调用　B. 只回收非托管内存　C. 会立刻释放所有引用对象　D. 强制回收可能造成卡顿，不应滥用

A每帧调用
B只回收非托管内存
C会立刻释放所有引用对象
D强制回收可能造成卡顿，不应滥用
查看答案与解析

正确答案：D

`GC.Collect` 触发完整回收，可能造成明显卡顿，且不会释放仍有引用的对象。应通过减少分配和对象池解决问题。 {% endhideBlock %}

5. 关于 `ValueTask`，下列说法正确的是？ A. 可以任意多次 await　B. 一般只能消费一次，重复 await 可能异常　C. 不能返回结果　D. 一定比 Task 慢

C不能返回结果
D一定比 Task 慢
查看答案与解析

正确答案：B

`ValueTask` 是为减少分配设计的，通常只能 await 一次；多次 await 或保存后重复消费可能触发未定义行为。 {% endhideBlock %}
