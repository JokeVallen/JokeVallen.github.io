一、客观题

1. asmdef 的主要作用是？

A明确程序集边界
B自动压缩纹理
C生成网络协议
D替代所有命名空间
查看答案与解析

正确答案：A

asmdef 控制程序集划分与依赖方向，减少全量编译和循环依赖。

反馈本题

2. Addressables 远程内容更新后通常需要？

A重新安装应用
B下载新的 Catalog
C删除全部缓存
D关闭 CDN 网络
查看答案与解析

正确答案：B

Catalog 是资源地址与版本索引，内容更新需要同步更新 Catalog。

反馈本题

3. AssetBundle 资源冗余的常见原因是？

A图集尺寸过大
B没有使用 LZ4
C共享资源未提公共包
D没有开启 Mipmap
查看答案与解析

正确答案：C

多个包各自包含同一份共享资源，会导致包体和内存重复。

反馈本题

4. 使用反射的代码在 IL2CPP 裁剪后失效，应通过什么保留类型？

A压缩纹理资源
B配置网络协议
C自动生成图集
D防止反射类型被裁剪
查看答案与解析

正确答案：D

link.xml 用于保留反射、序列化或热更需要的类型，避免被裁剪。

反馈本题

5. HybridCLR 的主要特点是？

AAOT 加解释器
B只能热更资源
C只能用于 Android
D不需要构建流程
查看答案与解析

正确答案：A

HybridCLR 通过 AOT 与解释器结合补足动态代码能力，适合纯 C# 热更。

反馈本题

6. 没有返回 Task 的异步方法，异常通常在哪里暴露？

A一定编译失败
B异常难以被捕获
C不能使用 await
D只能用于 Editor
查看答案与解析

正确答案：B

async void 没有可等待 Task，异常会直接抛到同步上下文。

反馈本题

7. 异步操作绑定对象生命周期应使用？

AGC.Collect
B静态事件
CCancellationToken
DResources.Unload
查看答案与解析

正确答案：C

CancellationToken 可以在对象销毁或场景切换时取消异步操作。

反馈本题

8. 对象池复用对象前必须先完成什么？

A无限增长不回收
B每次重新 new
C只用于 UI 元素
D重置状态并限制容量
查看答案与解析

正确答案：D

复用必须清理状态并限制容量，避免内存持续增长。

反馈本题

9. 动态 UI 频繁重建时，应如何隔离静态 UI？

A拆到不同 Canvas
B放在同一个 Canvas
C全部关闭合批
D每帧强制重建
查看答案与解析

正确答案：A

拆分 Canvas 可以缩小重建范围，避免动态 UI 影响静态 UI。

反馈本题

10. TMP 中文字体图集频繁扩容应如何处理？

A每次动态加字
B预生成常用字符集
C关闭字体回退
D每帧重建图集
查看答案与解析

正确答案：B

预生成常用字符集、配置 Fallback 并拆分图集可以避免频繁扩容。

反馈本题

11. SRP Batcher 主要优化什么？

A音频解码流程
B网络同步过程
C减少材质状态切换
D脚本编译过程
查看答案与解析

正确答案：C

SRP Batcher 通过持久化材质数据减少 CPU 侧的渲染状态切换。

反馈本题

12. GPU Instancing 最适合什么场景？

A大量不同材质
B单个 UI 文本
C每帧新建网格
D大量相同网格材质
查看答案与解析

正确答案：D

相同网格与材质的大批量对象可以用 Instancing 合并绘制。

反馈本题

13. Overdraw 主要消耗什么资源？

AGPU 填充率
B磁盘 IO
C网络带宽
DCPU 主线程
查看答案与解析

正确答案：A

同一像素被多次绘制会增加 GPU 填充率压力。

反馈本题

14. 排查资源泄漏最有效的工具通常是？

AAnimator
BMemory Profiler
CNetwork Profiler
DAudio Mixer
查看答案与解析

正确答案：B

Memory Profiler 可以抓取快照并查看对象引用链。

反馈本题

15. 按渲染顺序查看每个 DrawCall 状态，应使用什么工具？

AMemory Profiler
BNetwork Profiler
CFrame Debugger
DAnimator
查看答案与解析

正确答案：C

Frame Debugger 按渲染顺序展示 DrawCall 与状态。

反馈本题

16. .NET GC 的代数通常是？

A只有一代
B一共五代
C由 CPU 决定
D0/1/2 三代
查看答案与解析

正确答案：D

新对象进入 0 代，存活越久越可能晋升到 1、2 代。

反馈本题

17. ArrayPool<T> 的正确使用方式是？

A租用后归还并清理
B租用后不归还
C每次新建一个池
D只能用于值类型
查看答案与解析

正确答案：A

ArrayPool 复用数组减少 GC，但必须归还，敏感数据还应清理。

反馈本题

18. Span<T> 的主要限制是？

A可以随意进行装箱
B不能跨 await 保存
C可以作为类字段保存
D只能存储引用类型
查看答案与解析

正确答案：B

Span 是 ref struct，不能装箱、不能作为类字段、不能跨 await 保留。

反馈本题

19. 简单计数场景更适合使用？

Alock 包裹全部
B每次 GC.Collect
CInterlocked 原子操作
D新建线程同步
查看答案与解析

正确答案：C

Interlocked 提供原子自增与交换，开销通常低于完整锁。

反馈本题

20. 在 Task.Run 中访问 Unity API 会怎样？

A完全支持
B自动切回主线程
C只在 Editor 报错
D通常不允许
查看答案与解析

正确答案：D

Unity 大部分 API 不是线程安全的，需要切回主线程更新场景对象。

反馈本题

21. TCP 与 UDP 的主要区别是？

ATCP 可靠，UDP 不保证
BTCP 无连接，UDP 有连接
CUDP 一定比 TCP 快
D两者行为完全一样
查看答案与解析

正确答案：A

TCP 提供可靠有序字节流，UDP 更轻量但不保证可靠与顺序。

反馈本题

22. KCP 通常建立在什么协议之上？

AHTTP 文本协议
BUDP 数据报协议
CFTP 文件协议
DSMTP 邮件协议
查看答案与解析

正确答案：B

KCP 在 UDP 之上实现可靠传输，兼顾低延迟与可靠性。

反馈本题

23. 状态同步的主要特点是？

A只传输输入
B客户端完全确定性
C服务器同步权威状态
D不需要服务器
查看答案与解析

正确答案：C

状态同步由服务器下发权威状态，更容易防作弊。

反馈本题

24. 帧同步的主要特点是？

A传输完整场景状态
B不需要确定性
C只能用于单机
D传输输入并确定性演算
查看答案与解析

正确答案：D

帧同步传输玩家输入，各客户端按确定性逻辑演算。

反馈本题

25. 热更新版本管理最关键的是？

A资源与代码版本一致
B只更新客户端
C不需要 CDN
D不需要校验
查看答案与解析

正确答案：A

必须保证程序集、资源、配置版本匹配，否则容易出现兼容问题。

反馈本题

26. 灰度发布的主要目的是？

A一次性全量推送
B小范围验证后逐步放量
C完全跳过测试
D删除旧版本
查看答案与解析

正确答案：B

灰度可以控制影响面，观察崩溃率和关键指标后再扩大范围。

反馈本题

27. 热更新回滚方案必须具备什么？

A只保留最新版本
B每次覆盖安装包
C可恢复的旧版本与清单
D关闭日志上报
查看答案与解析

正确答案：C

必须保留可恢复的旧版本、版本清单和校验机制。

反馈本题

28. 以下哪项不是热更新必须保证的？

A版本一致性
B下载校验
C失败回滚
D每次全量重装
查看答案与解析

正确答案：D

热更新追求增量与可回滚，全量重装不是必须且成本高。

反馈本题

29. 以下哪项通常不能降低 GC 分配？

A缓存组件引用
B在 Update 中拼接字符串
C使用对象池
D使用 NonAlloc API
查看答案与解析

正确答案：B

字符串拼接会产生新的字符串对象，增加托管堆分配。

反馈本题

30. 以下哪项不是合理的资源分包原则？

A按模块划分
B按更新频率划分
C每个文件单独一个包
D兼顾加载与依赖
查看答案与解析

正确答案：C

每个文件单独打包会带来大量包和依赖管理成本，通常不是合理原则。
