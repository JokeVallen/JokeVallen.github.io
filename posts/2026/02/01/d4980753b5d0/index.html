Unity的ScriptableObject的生命周期函数

更新于2026-03-19|Unity开发
|浏览量:

生命周期函数

函数名 官方说明
Awake 当 ScriptableObject 脚本启动时，将调用此函数。
OnEnable 当对象加载时，会调用此函数。
OnDisable 当可脚本化对象超出作用域时，将调用此函数。
OnDestroy 当可脚本化对象将被销毁时，将调用此函数。
…… ……

参考自2020.3版本官方文档

测试结果

编辑器时（非构建项目）

  • ScriptableObject.CreateInstance：Awake -> OnEnable

  • 通过 CreateAssetMenu 创建：Awake -> OnEnable

  • 通过 Project 面板删除 asset 文件：不会触发

  • 脚本重新编译：OnDisable -> OnEnable

  • 非播放模式下：

    • 通过 AssetDatabase.LoadAssetAtPath 加载：Awake -> OnEnable
    • 通过 DestroyImmediate(obj, true) 销毁：OnDisable -> OnDestroy

  • 播放模式下：

    • 通过 AssetDatabase.LoadAssetAtPath 加载：Awake -> OnEnable
    • 通过通过 Destroy(obj) 销毁：OnDisable -> OnDestroy
    • 通过 DestroyImmediate(obj) 销毁：OnDisable -> OnDestroy

测试基于 Unity 的 Test Framework，分别在 EditMode 和 PlayMode 下完成。未列举到的情况后续将进行补充，非专业测试人员，测试结论请酌情参考。

运行时（构建项目）

项目中没有场景对象直接引用 ScriptableObject 的 asset

  • 进入场景：无
  • 通过 Resources.Load<T>(string path) 将 ScriptableObject 的 asset 加载到内存中：Awake -> OnEnable
  • 通过 Resources.UnloadAsset(Object assetToUnload) 将 ScriptableObject 实例卸载：OnDisable
  • 调用 DestroyImmediate(Object obj) 将内存中的 ScriptableObject 实例销毁：OnDisable -> OnDestroy
  • 调用 Destroy(Object obj) 将内存中的 ScriptableObject 实例销毁：OnDisable -> OnDestroy
  • 调用 DestroyImmediate(Object obj, bool allowDestroyingAssets) 将内存中的 ScriptableObject 实例销毁：OnDisable -> OnDestroy
  • 调用 ScriptableObject.CreateInstance<T>() 创建 ScriptableObject 实例：Awake -> OnEnable
  • 退出场景：OnDisable

项目中存在场景对象直接引用 ScriptableObject 的 asset

引用 ScriptableObject 的 asset 的游戏对象默认处于激活状态
  • 进入场景：Awake -> OnEnable
  • 将游戏对象设置为未激活状态：无
  • 将游戏对象设置为激活状态：无
  • 调用 Destroy(Object obj) 销毁引用 ScriptableObject 的游戏对象：无
  • 调用 Destroy(Object obj) 移除引用 ScriptableObject 的组件：无
  • 退出场景：OnDisable
引用 ScriptableObject 的 asset 的游戏对象默认处于未激活状态
  • 进入场景：Awake -> OnEnable
  • 退出场景：OnDisable
